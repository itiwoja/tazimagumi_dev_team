# 0. v5.0 改訂サマリ（v4.2 からの変更点）

**v4.2 では市場・競合・薬機法リスクを整理したが、「世間に浸透する現実的なアプリになるか」という観点では、ネイティブアプリ単体の前提がまだ弱かった。本 v5.0 では、卒制 MVP の主戦場を「社会全体への普及」ではなく「中間発表で説得力のある実証データを出すこと」と定義し直し、導線をアプリストア検索中心から PWA / LINE / QR / SNS 経由へ寄せる。同時に、サービスの主役を「診断」ではなく、初期チェックから最初の1本、朝夜の使い方、髭剃り前後のケア、継続支援までをつなぐ **身だしなみロードマップ型の伴走体験** として再整理する。**

| **重要度** | **R# / 変更点** | **変更理由（要旨）** |
| --- | --- | --- |
| **🔴 致命的** | **R12：薬機法表現の矛盾を再修正** | **v4.2 で NG にした「同じ悩みのユーザーから選ばれている」系表現が、10.1 の OK 例に残っていたため全削除。推薦理由は客観ランキング・出典付きレビュー数・56効能範囲内の成分タグに限定する** |
| **🔴 致命的** | **R13：浸透戦略を PWA / LINE / QR / SNS 起点へ格上げ** | **美容アプリを能動検索しない層に届けるには、アプリストアではなく URL・QR・LINE WebView・SNS 投稿から「初期チェックで自分用ロードマップが出る」体験として開かせる導線が現実的。PWA を MVP の主配信チャネルとして明記する** |
| **🟡 高** | **R14：第1次調査を n=40〜60 に拡張** | **友人・学内 10〜20 名では説得力が弱いため、学外・美容無関心層・30代以上を含める。アプリ導入意向と PWA / LINE 導線の受容性を比較できる設問に変更する** |
| **🟡 高** | **R15：KPI を「浸透可能性」寄りに再設計** | **クリック率だけでは現実の利用意向が測れないため、初期チェック完了率・ロードマップ納得度・実行意向・再利用意向・チャネル受容性を主要 KPI に変更する。9月プロトタイプ評価は最低15名、目標30名で測定する** |
| **🟡 高** | **R16：コミュニティを縮小し、FAQ / 相談テンプレ / 学内限定検証へ変更** | **投稿型コミュニティは薬機法・運営継続・モデレーション負荷が大きいため、卒制 MVP では実装しない。初心者の相談価値は FAQ・相談テンプレ・学内限定の投稿検証で確認する** |

中間発表では「4 つの調査の集計軸が違うので並べて読むこと」を一言添える方針とし、企画書では**「市場が拡大基調にある」という事実は 4 出典いずれでも一致している**ことを強調する。詳細は 13 章 Q&A の Q16 を参照。

**一方で、市場成長と裏腹に、男性ユーザーの「選び方の困難」は解消されていない。**

- **男性向けスキンケア商品は急増（オルビスミスター、バルクオム、UNO、NULL、DiNOMEN、Lab Series、Kiehl's メンズ等）。一方で、選択肢が多すぎて「結局どれを買えばいいのか」が分からない状態が深刻化**

- **ドラッグストアの男性向けコーナーも限定的で、棚を見て判断するのは経験者には可能だが初心者には不可能（村上の沖縄市内ドラッグイレブンでの体験：棚を見て判断できず、何も買わずに帰宅）**

- **「美容に詳しい人に聞ける環境」は、男性の場合 LINEオープンチャット・Instagram・YouTube・Reddit r/AsianBeauty などに分散しており、アプリ内で完結する初心者向けの中立的な相談先は乏しい**

- **沖縄特有の事情：高湿度・強紫外線・年間平均気温の高さにより、皮脂分泌が多い男性の肌負担が他県より大きい**

# 2. トレンド

- **「身だしなみ」としてのスキンケアが10〜30代男性の中で標準化。男性のスキンケア実施率は2025年5月時点で約60.2%、化粧水使用率は69.5%まで上昇し、「意識高め層」から多数派へ移行（くふう総研 2025年5月、N=1,280）。大学生男性の日常的スキンケア実施率は83.0%、メンズコスメ利用経験率は前年比+11.3ptで47.0%（TesTee Lab 2024年5月、N=600）**

- **Z世代を中心に、SNSで自分の顔を見る機会が増え、清潔感重視の価値観が浸透**

- **海外ブランド（韓国・フランス・アメリカ系）の日本市場参入が活発化し、選択肢が爆発的に増加**

- **「面倒くさい」を解消するオールインワン製品が主流化。富士経済も2025年見込でオールインワンを市場牽引役と指摘**

- **男性の基礎化粧品使用きっかけは「肌の乾燥やトラブル改善のため」（31.2%）、「自分磨きの一環」（24.1%）が上位（インテージ調べ）**

- **一方で「身だしなみ」と「美容」の境界線は男性にとって心理的バリアが高く、「美容」と言われた瞬間に離脱する層が一定数いる**

# 3. ユーザー調査

## 3.1 ターゲット再定義（v2.0 → v3.0 で絞り込み）

| **優先度** | **年齢層** | **特徴と狙い方** |
| --- | --- | --- |
| **プライマリ** | **15〜35歳男性の美容初心者** | **スキンケアに詳しくなく、ドラッグストアやECで「最初に何を買い、朝夜どう使えばいいか」で止まっている層。皮脂・ニキビ・毛穴・ひげ剃り後の違和感が主訴。予算は最初の3点で〜3,000円中心。中間発表のデモはこの層の「最初の一歩」を完璧に攻略する。** |
| **セカンダリ** | **36〜49歳男性の再入門層** | **エイジング・テカリ・毛穴・乾燥の複合悩みがあり、若い頃の自己流ケアから見直したい層。予算3,000〜10,000円。MVPでは同じロードマップ構造を使い、年齢層別の補足は最小限に留める。** |
| **参考対応** | **50代以上** | **シミ・たるみ・乾燥が主訴。卒制スコープでは「文字大きめモード」のアクセシビリティ対応のみ。プライマリ機能の検証は次回拡張で。** |

**最初に解く利用シーン**：本企画が最優先で解くのは、「美容に強い関心がある人」ではなく、ひげ剃り後の違和感、ニキビ、テカリ、他者からの指摘などをきっかけに、初めてスキンケアを始めようとした男性が、店頭やECの商品数・専門用語・使う順番で止まる瞬間である。

**MVPでの約束**：ユーザーに「美容知識」を学ばせるのではなく、3分以内に **今日買う候補3点** と **今夜・明日の朝にやる順番** まで決める。これを達成できない機能は、中間発表の主役にしない。

## 3.2 ターゲット共通の課題

- **美容用語が分からない（ヒアルロン酸、セラミド、ナイアシンアミドなどの成分名）**

- **自分の肌タイプ（乾燥/脂性/混合/敏感）すら把握していない**

- **最初に買う商品と、買った後に朝夜どう使うかが分からない**

- **肌磨き・髭剃り後のケアの「順番」が分からない**

- **続かない（効果実感まで肌のターンオーバー約28日、短期では「変化が見えない」）**

- **男性特有の肌悩み（赤み・かゆみ・吹き出物・乾燥肌・敏感肌・髭剃り起因炎症）への情報が分散**

- **相談できる環境がアプリ内にない（LINEオープンチャット・Instagramコミュニティへの離脱が必要）**

## 3.3 ユーザー調査計画（2 段階）

**企画の根拠を「データで示せる」状態にするため、2 段階のユーザー調査を実施する。第1次は前提検証（認知・実態・チャネル受容性）、第2次はプロトタイプ評価。v5.0 では「アプリを入れてくれるか」だけでなく、「URL / QR / LINE なら使うか」を必ず測る。**

### 3.3.1 第1次調査：認知・実態調査（5月実施、完了目標：5月31日）

**目的**：「男性が美容を相談しにくい」「何を買えばいいか分からない」という企画の前提に、定量的な根拠を与える。

| 項目 | 内容 |
| --- | --- |
| **対象** | 15〜49歳男性 40〜60 名。学内だけでなく、学外の友人・家族・アルバイト先・SNS 経由を含める。最低条件として、30代以上を15名以上、美容・スキンケアに無関心な層を10名以上含める |
| **方法** | Google フォーム（9 問、所要 3 分以内）／LINE・Discord・QRコード・SNS で配信 |
| **完了目標** | 5 月 31 日までに集計完了 |
| **結果反映** | 6 月中旬発行予定の中間版資料に組み込み、中間発表スライドにも「実データ」として掲載 |

**確定した 9 問（設問文・選択肢）**：

1. **現在、何らかのスキンケア（洗顔以外）をしていますか？**
   - 毎日している／たまにしている／していない

2. **（②前問で「していない」「たまに」を選んだ方）スキンケアをしていない／続かない理由は？（複数選択可）**
   - 面倒くさい／何を買えばいいか分からない／効果がよく分からない／必要性を感じない／お金がもったいない／恥ずかしい・男性らしくないと感じる／その他

3. **男性の友人と美容・スキンケアの話をしますか？**
   - よく話す／たまに話す／ほとんど話さない／全く話さない

4. **スキンケアについて相談したい相手はいますか？（複数選択可）**
   - パートナー／家族／同性の友人／店員（ドラッグストア・美容部員）／皮膚科医・専門家／オンラインの匿名コミュニティ／誰にも相談したくない／誰でもいいから聞きたい

5. **現在、美容・スキンケア系のアプリを使っていますか？**
   - 使っている（具体的なアプリ名を任意記入）／過去に使ったがやめた／使ったことがない

6. **「3分の初期チェックで、自分向けの身だしなみロードマップが出るページ」の URL が送られてきたら使いますか？**
   - 使う／内容次第で使う／使わない

7. **同じ初期チェック・ロードマップ機能を使う場合、どの入口なら一番使いやすいですか？**
   - Web URL／LINE 内で開く／QRコード／アプリストアからインストール／使わない

8. **診断結果に「おすすめ商品」と「なぜそれを提案するか」が表示されたら、信頼できますか？**
   - 信頼できる／説明が分かりやすければ信頼できる／あまり信頼できない／信頼できない

9. **診断結果の商品が 1,000〜3,000 円程度なら、実際に買ってみたいと思いますか？**
   - 買いたい／候補として見る／買わない／価格次第

**結果の活用方針**：

- 設問②で「何を買えばいいか分からない」が上位なら、6 タイプ即決 UI と初心者向けロードマップ設計の妥当性を補強
- 設問③④で「相談相手がいない」が多ければ、FAQ・相談テンプレ・学内限定検証の必要性を補強
- 設問⑤で既存アプリの認知が低く、設問⑥⑦で URL / LINE / QR の受容性が高ければ、PWA 主配信の妥当性を補強
- 設問⑧⑨で「信頼できない」「買わない」が多ければ、推薦理由の説明・商品価格帯・中立性・朝夜ステップの見せ方を修正する
- 想定と異なる結果が出た場合は、中間版資料で該当章を必ず修正する（仮説に固執しない）

### 3.3.2 第2次調査：プロトタイプ評価（9月実施、完了目標：9月30日）

**目的**：MVP プロトタイプの使用感を計測し、第12章 KPI の事前検証として中間発表データに反映する。

| 項目 | 内容 |

## 3.4 ユーザー獲得トリガーの定義

**「スキンケアで困っている男性」と「アプリを使う男性」は必ずしも一致しない。困っていても「面倒くさい」「どうせ分からない」で調べない層は、アプリストアで能動的に検索しない。本アプリが届くべき層に届くためには、アプリを開くきっかけ（トリガー）を明確にし、それに応じた認知導線を設計する必要がある。**

| **トリガー** | **具体例** | **刺さるアプローチ** |
| --- | --- | --- |
| **肌トラブルの可視化** | ひげ剃り後の赤み・ニキビが鏡で気になり始める | 「ひげ剃り後の荒れ」タイプを前面に出した訴求 |
| **他者からの指摘** | パートナー・友人に「肌荒れてない？」と言われる | 「言われてから始めた人向け」の導線設計 |
| **SNS・動画経由** | TikTok / YouTubeで「メンズスキンケア入門」を視聴 | 短時間で結論が出る⑥「とにかく始めたい」タイプへの誘導 |
| **毎日の痛み** | カミソリ負けが毎回続き、限界を感じる | 「ひげ剃りケアモード」を入口にしたLPや紹介文 |

### 3.4.1 マルチチャネル戦略（v5.0 で本筋化）

**前提**：上記トリガーがあっても、男性スキンケア初心者がアプリストアで「美容アプリ」を能動検索する可能性は高くない。したがって v5.0 では、ネイティブアプリを主配信チャネルにせず、PWA / LINE / QR / SNS 経由で「3分の初期チェックから自分用ロードマップが出るツール」として開かせる導線を本筋にする。

**判断基準**：第 1 次調査の設問⑥⑦で、Web URL / LINE / QR のいずれかを選ぶ回答が合計 60% を超えた場合、PWA 主配信を正式採用する。アプリストアからのインストール希望が 40% を超えない限り、ネイティブアプリ開発は卒制スコープ外のままとする。

| --- | --- | --- |
| **PWA（Web URL 直アクセス）** | SNS・QR コードから直接起動。アプリストア審査を経ずに体験提供 | MVP の主配信チャネル |

**設計含意**：初期チェック・推薦・薬機法ガードレール・朝夜ステップ表示などの核機能は **第 9 章のフロントエンド／バックエンド構成のまま再利用できる**。同一の React アプリを PWA / LINE WebView / 将来のネイティブ WebView で表示する構成にし、11月中間発表では「QRを読み取る → 初期チェック → 自分用ロードマップ → 最初の1本と使う順番を見る」体験を最短導線として見せる。

# 5. 業界の課題深堀

## 課題① 結局何を買えばいいのか分からない

- **商品が多すぎて選べない（マイベスト・LIPSのメンズランキングだけで79アイテム超）**

- **専門用語（ヒアルロン酸、セラミド、ナイアシンアミド、BHA、AHA等）が分からない**

- **自分の肌タイプを把握していないため、棚で迷う**

- **買った後の使う順番が分からず、「商品を選ぶ問題」と「毎日実行する問題」が同時に発生している**

## 課題② 男性特有の肌悩みに対応した情報が少ない

- **髭剃り後の肌荒れ、皮脂分泌の多さなど、男性ホルモン由来の悩み**

- **赤み・かゆみ・吹き出物・乾燥肌・敏感肌・髭剃り起因炎症など、男性特有の症状群への情報が分散**

- **女性向けの情報を流用しても、男性の肌（水分量約半分、皮脂量2〜3倍）には合わない**

- **髭剃りで毎日肌に負担がかかり、刺激のある商品を選ぶと負担が蓄積**

## 課題③ 習慣化が難しい

- **「面倒くさい」「効果が見えない」で続かない**

- **スキンケアの順序や頻度が分からず、自己流で挫折**

- **効果が出るのが遅く（ターンオーバー約28日）、短期では成果が見えにくい**

- **カレンダー記録だけでは「行動」の蓄積は見えるが「成果」が見えず、虚無感に繋がる**

## 課題④ 相談できる相手がいない

- **男性同士で美容の話題はしにくい風潮が根強い**

- **美容部員やドラッグストア店員に聞きにくい（特に若年層）**

- **家族・パートナーへの相談もハードルが高い**

- **既存の相談環境はLINEオープンチャット・Instagram・Redditに分散**

### ④ 推薦理由の説明（薬機法準拠、v4.2 改訂・R3 対応）

- **「あなたの肌タイプに合う」「あなたに最適」ではなく「楽天市場メンズスキンケア部門 ○月度ランキング上位」「使用感（テクスチャ・香り・べたつき感など）に関するレビュー数 ○件以上」のように、客観データを出典付きで提示する**

- **成分マッピングは「うるおいを与える」「肌をすこやかに保つ」「余分な皮脂を落とす」「ニキビを防ぐ（医薬部外品のみ）」など、化粧品標榜可能な56効能の範囲内に限定し、効能タグを動的生成する**

- **「効く」「治る」「消える」「白くなる」「絶対」「100%」などの断定・保証表現は使用しない**

- **【v4.2 で削除した表現】**：「**同じ肌タイプの方によく選ばれている**」「**同じ悩みのユーザーから支持されている**」は、医薬品等適正広告基準で禁止されている「他者への推薦」の暗示にあたるとの最新解釈（2026/05/13 調査）に基づき、v4.2 で本企画から全削除する。9 月末の薬剤師・公的窓口チェックで最終確認する

### ⑥ 髭剃りケアモード（簡易版、v4.2 改訂・R8 対応）

**男性特有の悩みである髭剃り後のケアに特化した独立機能。MVPでは「タイミングを選ぶ成分の有無」と「使う時間帯の図解」に絞る：**

- **成分マッピング表示：商品ページで、髭剃り直後の使用にはタイミングを選ぶ成分（エタノール、メントール、香料、サリチル酸等）を客観的に表示し、剃った直後に使うか、15分以上空けてから使うかをユーザーが選べる形で提示する。安全性の評価・刺激の強弱判定はアプリ側で行わない**

- **髭剃りルーティン可視化：「剃る前 → 剃った後すぐ → 15分後」の時系列フロー図。各時間帯に「使用を推奨する成分」「タイミングをずらすことを推奨する成分」を客観事実として並べる**

- **成分チェックリスト：商品ページで、上記の「タイミングを選ぶ成分」（エタノール、メントール、香料、サリチル酸等）が「含まれているか／含まれていないか」を一覧表示する。アプリは成分の有無という事実のみを提示し、安全性・刺激の強さの評価や保証は一切行わない。デモ用10商品で実装。**

**v4.2 で変更した表現（R8 対応）**：「**髭剃り直後に刺激になりやすい成分**」「**髭剃りに注意が必要な成分**」「**髭剃り負担**」は、安全性評価の暗示として薬機法上のリスクがあるため、本企画では一律「**タイミングを選ぶ成分**」「**タイミングをずらすことを推奨する成分**」「**髭剃り後のケアが必要な状態**」に統一する。

## 8.4 想定する収益モデル（卒制スコープ外、議論用）

**卒制版ではアプリ内に広告・アフィリエイトリンクを一切実装しない。** 中立性を担保することが最優先で、収益化はあくまで「将来サービスとして継続する場合の議論用」として整理する。

### 8.4.1 卒制版の方針：完全広告フリー

- **アプリ内広告ゼロ**：バナー広告、インフィード広告、商品の優先表示などを一切実装しない
- **アフィリエイトリンクゼロ**：楽天アフィリエイト・Amazon アソシエイトのリンクは設置しない。商品詳細への遷移は楽天市場の通常リンク（手数料率の影響を受けないもの）に統一
- **推薦アルゴリズムの中立性**：手数料率・売上ランクを推薦に反映させない。診断結果と商品マスターのタイプ別タグのみで決定（第7章・第10章のガードレールに準拠）
- **利用規約への記載**：「本アプリは卒業制作版として広告なしで運営しています。表示される商品はアフィリエイト契約に基づくものではありません」と明記

### 8.4.2 将来サービスとして継続する場合の収益構造（議論用）

**もし卒制提出後にチームまたは後継組織がサービスを継続する場合**、以下4つの収益源を組み合わせる構造を想定する。順番は導入のしやすさと中立性への影響度で並べた。

| **#** | **収益源** | **想定規模感** | **中立性への影響** | **採用ハードル** |
| --- | --- | --- | --- | --- |
| **①** | **楽天アフィリエイト**（楽天アフィリエイト個人会員、商品リンク経由の購入で 2〜10% 手数料） | **小〜中**（DAU 1,000 で月数千〜数万円程度） | **中**（推薦アルゴリズムから手数料率を完全に排除して中立性を担保） | **低**（楽天 ID があれば即時開始可能、売上ハードルなし） |
| **②** | **Amazon アソシエイト** | **小〜中** | **中**（同上） | **中**（180 日以内に 3 件の適格売上が必要。MVP では不採用） |
| **③** | **有料プラン**（詳細レポート・成分相性分析・薬剤師オンライン相談など、月額 300〜500 円想定） | **中〜大**（コア層に刺されば収益の主軸になり得る） | **低**（無料機能の質を落とさなければ問題なし） | **高**（決済システム・特商法対応・カスタマーサポート体制が必要） |
| **④** | **メーカー直契約**（広告なしのプレースメント枠ではなく、商品マスター掲載料 or 検証データ提供契約） | **中〜大** | **要設計**（メーカー資金が推薦結果に影響しないよう、編集権と営業権を完全分離する組織設計が必要） | **高**（法人化必須、薬機法・景表法専門家の常勤が必要） |

**段階的な収益化ロードマップ（想定）**：

1. **Phase 1（卒制提出〜半年）**：完全無料・広告なし運用を継続。ユーザーデータと利用実績を蓄積
2. **Phase 2（半年〜1 年）**：楽天アフィリエイトのみ導入。手数料率を推薦から完全に排除する技術的検証を実施
3. **Phase 3（1 年〜2 年）**：有料プランの提供開始。無料版の機能を一切削減しない方針を堅持
4. **Phase 4（2 年〜）**：法人化を視野に入れた場合のみ、メーカー直契約を検討

### 8.4.3 中立性を裏切らないための設計原則

- **編集権と営業権の分離**：推薦アルゴリズムを設計・運用するメンバーは、アフィリエイト・スポンサー契約の交渉に関与しない
- **データソースの透明化**：商品マスター・成分タグの更新履歴を内部で監査可能にし、外部からの問い合わせに応じて開示可能な状態にしておく
- **収益化の事前告知**：将来アフィリエイト等を導入する場合、利用規約改訂とアプリ内告知を最低 30 日前に行う
- **レビュー投稿の独立性**：将来レビュー・口コミ系の投稿を扱う場合でも、投稿が収益に直結する設計は採用しない（ステマ防止）

**Q&A 連動**：本節は第 13 章 Q5「収益モデルは？中立的推薦とアフィリエイト収益は矛盾しないか？」の回答根拠として使用する。中間発表で問われた場合、本節の表をスライドに展開して説明できる状態にしておく。

# 10. 薬機法ガードレール（新設）

**化粧品を扱うアプリケーションのため、医薬品、医療機器等の品質、有効性及び安全性の確保等に関する法律（薬機法）と医薬品等適正広告基準を遵守する。本企画では以下のガードレールを企画段階で固定する。**

## 10.1 NG表現と OK 言い換えテンプレート

| **NG表現（使わない）** | **OK表現（言い換え）** | **根拠** |
| --- | --- | --- |
| **ニキビを治す／消す／治る** | **「肌を清潔に保つ」「（医薬部外品の場合）ニキビを防ぐ」** | **一般化粧品では治療効果不可** |
| **シミが消える／白くなる** | **「日焼けによるシミ・そばかすを防ぐ（医薬部外品）」「メーキャップ効果で肌を明るく見せる」** | **化粧品 56 効能範囲外** |
| **皮脂を抑える** | **「余分な皮脂を落とす」「さっぱりとした感触」** | **一般化粧品では「抑える」不可** |
| **毛穴改善／毛穴を引き締める** | **「毛穴の汚れを落とす」「キメが整い毛穴が目立ちにくい肌へ（印象範囲内）」** | **「毛穴改善」は56効能範囲外** |

| **あなたに必ず合う／効果保証** | **「楽天市場メンズスキンケア部門 〇月度ランキング上位」「あなたの肌タイプ（脂性／乾燥／混合／敏感）に推奨される成分（うるおいを与える成分／肌をすこやかに保つ成分等、56効能の範囲内）を含む商品」** | **保証表現の禁止** |
| **同じ肌タイプの方によく選ばれている／〇〇の方から支持されている（v4.2 で NG に格上げ・R3 対応）** | **「楽天市場メンズスキンケア部門 ○月度ランキング上位」など客観データ＋出典明示、または「あなたの肌タイプ向けに推奨される成分（56効能の範囲内）を含む商品」** | **医薬品等適正広告基準で「他者への推薦」は暗示的な効能保証として禁止。本企画では一律削除する** |
| **No.1／日本一／最高** | **「楽天市場メンズスキンケア部門 〇月度ランキング1位」（客観データ明示）** | **最大級表現は客観データ必須** |
| **（化粧品の）使用前後比較画像をコミュニティ公開** | **本人＋招待者の完全プライベート機能のみ。公開コミュニティでは表示しない** | **使用前後画像は効能効果の暗示にあたる** |
| **（化粧品の）体験談・口コミでの効果謳い** | **「使用感の感想」「香りの印象」など使用感に限定。AI Moderation で効果効能ワードを警告** | **化粧品では体験談広告は原則禁止** |
| **医師・専門家・有名人の推薦** | **使用しない（卒制スコープでは想定なし）** | **薬機法 66 条 2 項の保証広告禁止** |

## 10.2 デザイン・実装レベルのガードレール

- **成分タグの表示は「化粧品の効能の範囲（56効能）」のリストから動的生成する。タグマスターを最初に整備**

- **医薬部外品（薬用化粧品）と一般化粧品は商品マスターで区別し、表示できる効能タグを分岐**

- **投稿・相談テンプレ・推薦理由文のチェックリスト（v5.0 改訂、200語規模）**：
  - 断定・保証表現：「治る／効く／消える／白くなる／絶対／100％／保証／医師推奨／ドクターズコスメ／必ず／確実」等
  - 効能効果の暗示：「ニキビが治った／肌荒れが治った／シミが消えた／毛穴がなくなった／浸透する（無条件）」等
  - 使用感と効能の混合表現：「ニキビが減った／赤みが引いた／黒ずみが薄くなった／毛穴が小さくなった／皮脂が止まった／一晩で／劇的に／3日間で／使用後すぐ」等
  - 体験談・他者推薦の暗示：「同じタイプの方によく選ばれている／〇〇さんも使っている／効果ありました／個人の感想ですが」等（「個人の感想です」免責文も無効）
  - 景表法ステマ規制：「ステマ／案件／タイアップ表記なしの商品紹介／PR 表記なしの推奨」等
  - 検出語に該当した投稿は即時保留、書き直しガイダンス画面（NG ワードと推奨言い換え例）を表示する

- **推薦理由文の生成テンプレートは事前に5〜10パターン用意し、AI 生成は「テンプレを埋める」運用に限定（自由生成は薬機法リスク）**

- **開発工程の節目で、教員・薬剤師資格保有者または公的相談窓口（都道府県薬務課等）に確認を依頼する計画を組み込む**

# 13. 質疑応答（想定 Q&A）

**Q0. スキンケアに関心のない男性がなぜこのアプリを使うのか？**

**A. **「スキンケアに関心がある男性」と「スキンケアに困っている男性」は別の層です。本アプリのターゲットは後者——困っているが何をすればいいか分からず、調べる気にもなれない層——です。この層がアプリを開くのは「美容への関心」ではなく、「ひげ剃り後の痛みが限界」「パートナーに肌荒れを指摘された」「鏡で自分のニキビが気になった」といった具体的なトリガーです。そのため訴求は「美容アプリを入れてください」ではなく、「QR / URL から3分で自分用の身だしなみロードマップが出る」という困りごと起点の言葉で行います。開いた後は⑥「何もわからない・とにかく始めたい」タイプが即座に最初の1本と使う順番を出す設計が、この層の離脱を防ぎます。

**Q1. 男性向けに特化する必要はあるのか？女性向けアプリで十分では？**

**A. **男性は皮脂分泌が女性の約2〜3倍多く、ひげ剃りによる肌負担も独自の課題です。さらに「美容について男性同士で話しにくい」という心理的バリアがあり、女性向けサービスでは取りこぼされている層が大きく存在します。男性専用にすることで、ターゲットの悩みに正面から応えられます。

**Q2. v2.0では「ブルーオーシャン」と書いていたが、競合は本当に少ないのか？**

**A. **v2.0の認識は誤りでした。gencos（メンズコスメ専門アプリ、肌タイプ診断あり、2023年〜）、LIPS（1000万人、メンズ独立ランキング有）、@cosme（Snow Beauty Mirror で肌診断）など競合は既に存在します。v5.0では「競合は存在するが、本企画の組合せ（日本人男性向け × 中立的推薦 × 髭剃りケア独立 × 初心者向け伴走ロードマップ）はまだ薄い領域」と認識を更新しました。差別化は具体的な4軸で説明できます。

**Q3. すでに価格.comや楽天市場があるのに、なぜ新しいアプリが必要？**

**A. **既存のECサイトは「商品リスト」を提供しますが、「自分に合うものを選ぶ」「買った後にどう使うか決める」プロセスはユーザー任せです。本アプリは初期チェックによって「最初の1本」「必要なセット」「朝夜の順番」「髭剃り前後の注意点」を一つのロードマップとして提示し、初心者の意思決定コストと実行コストを大幅に下げます。

**Q4. 診断の精度はどう担保する？**

**A. **23問の質問を肌タイプ・悩み・髭剃りスタイル・生活習慣・予算など複数軸でスコアリングし、組み合わせで判定します。スコアリングロジックは別紙「診断ロジック設計書」で詳細設計し、薬機法に準拠した表現で結果を提示します。3ヶ月ごとの再診断で肌の変化を追跡し、推薦と前回比較レポートを自動更新する仕組みを設けます。

**Q5. 収益モデルは？「中立的推薦」とアフィリエイト収益は矛盾しないか？**

**A. **主にアフィリエイト収益（楽天市場など）を想定します。中立性を担保するため、推薦アルゴリズムにはアフィリエイト手数料率を反映させず、肌タイプ・悩み・予算のみを推薦の根拠とします。アフィリエイト収益はあくまで運営継続のための原資という位置づけを利用規約に明記します。将来的には有料プラン（詳細レポート、専門家相談など）も検討。

**Q6. 商品データはどこから集める？価格.com APIを使うのでは？**

**A. **価格.com APIは2012年6月末で新規受付を終了しており、現在は利用できません。v5.0では「楽天市場API（2026年5月13日以降の新版、accessKey + Referer/Originヘッダー認証）」を主力とし、加えて自前の商品マスターDB（MVP 50 SKU → 卒制 200 SKU）を整備します。成分情報は OCR 内部管理ツールで成分表画像をテキスト化し、成分マスターと照合したうえで人間が最終確認します。ユーザー画面では楽天 API を直接叩かず、PostgreSQL のキャッシュを返すため、デモ当日の安定性を確保できます。

**Q7. 競合（gencos、LIPS、@cosme、BULK HOMME、オルビス肌カ.ル.テ等）が出てきたらどう差別化する？（v4.2 改訂・R1＋R2＋R7 対応）**

**A. **v4.1 までは「4軸の独自領域」と説明していましたが、2026年5月の前提検証で、LIPS「肌タイプ×成分相性診断」やオルビス「肌カ.ル.テ」など、診断・成分相性・カウンセリングに強い競合が既に存在することが判明しました。そのため v5.2 では、診断精度で正面から勝つ企画ではなく、診断結果を **「今日買う候補3点」「今夜やること」「明日の朝やること」「髭剃り前後の注意タイミング」** に変換するロードマップ体験として差別化します。競合が診断や商品レビューに強いほど、初心者には情報量が増えすぎるため、本企画は「最初の行動を決める」ことに絞ります。卒制スコープでは、(a) 男性初心者向けロードマップ、(b) 髭剃り前後の時間軸、(c) 複数ブランドの中立的候補提示、の3点に集中します。

**Q8. 開発スコープは？11月中間発表で何を見せる？**

**A. **MVPとして見せるのは「QRを読む → 6タイプ入口または23問初期チェック → 自分用ロードマップ → 最初に買う候補3点 → 今夜・明日の朝・髭剃り前後の順番を見る → これなら始められそうかを回答する」という1本の体験です。商品データは30〜50 SKUの手動整備データで固定し、楽天API本連携・OCR管理ツール・FAQ・相談テンプレ・習慣化グラフ・200 SKU運用は中間発表の必須範囲から外します。これにより、発表時は「広い機能一覧」ではなく「初心者が最初の行動に移れるか」を確実に検証できます。

**Q9. なぜ「2段階入口（6タイプ選択 + 23問初期チェック）」の構造にしたのか？また、なぜ6タイプなのか？**

**A. **まず6タイプの根拠について：男性の肌悩みを「原因の軸」で整理すると、皮脂分泌（テカリ）・水分不足（乾燥）・炎症（ニキビ・肌荒れ）・男性ホルモン×物理刺激（ひげ剃り荒れ）・加齢（くすみ・エイジング）の5軸に収束します。これに、どれにも当てはまらない完全初心者の受け皿を加えた計6タイプが、男性の悩みの入口を過不足なくカバーできる最小構成です。次に2段階構造の理由：ユーザー層が15〜49歳と幅広く、ITリテラシーやスキンケアへの熱量も大きく異なります。いきなり23問を出すと「面倒くさい」と離脱されるリスクが高い一方、6タイプだけでは精度が不足します。ライト層には直感で選べる入口を、複数悩み層・本気層には精密な初期チェックを用意し、どちらも最終的には「買うもの・使う順番・髭剃り前後の注意点」が分かるロードマップに着地させます。Garmin公式サイトのウォッチ選択UIなど、実証済みのUXパターンを参考にしています。

**Q10. AIで肌画像を解析する案はなぜ採用しなかった？**

**A. **当初はAI画像解析で肌スコアを数値化する案を検討しましたが、(1)撮影条件（光量・角度・カメラ）のブレで数値が安定しない、(2)AIの精度が「肌の状態」より「光の状態」を測ってしまうリスク、(3)顔写真を外部APIに送ることへのプライバシー懸念、の3点から採用を見送りました。代わりに、ユーザー自身の主観評価（毎週5段階）と23問再診断の比較を組み合わせた信頼性のある体験設計を採用しています。

**Q11. 薬機法の制約がある中で、コミュニティを作る価値はあるのか？**

**A. **相談価値はありますが、v5.0 では投稿型コミュニティを卒制 MVP から外します。理由は、効果体験談・Before/After・他者推薦表現の管理が重く、常時モデレーション体制が必要になるためです。代わりに、初心者FAQ、相談テンプレ、学内限定の相談文回収で「男性が基礎的な疑問をためらわず聞ける場」の価値を検証します。薬機法チェックは公開投稿ではなく、テンプレ文と学内検証データの目視レビューに限定します。

**Q12. ライン使い推奨は「中立的推薦」と矛盾しないのか？**

**A. **ライン使いは「初心者の習慣化を支える選択肢の一つ」として提示します。推薦UIでは個別最適推薦とライン使い統一推薦の2方式を併記し、ユーザーが選択できる構造にすることで中立性を保ちます。さらに3ヶ月後の再診断で「個別最適化に卒業しますか？」と問いかけ、ユーザーの成長段階に応じて推薦方式を進化させるフェーズ制を採用しています。

**Q13. 髭剃りケアモードを独立機能にした理由は？**

**A. **ひげ剃り起因の肌負担は男性ホルモンに直結する男性特有の悩みであり、女性向けアプリには存在しない領域です。これを単なる悩みタグの一つとして埋もれさせず、独立モードとして強調することで、(1)他アプリとの明確な差別化、(2)毎日髭を剃る男性の利用頻度向上、(3)発表時の機能訴求力強化、の3つの効果を狙えます。

**Q14. 薬機法対応はどう担保する？**

**A. **本企画書の第10章「薬機法ガードレール」で、NG表現とOK言い換えテンプレートを企画段階で固定しています。具体的には：①成分タグは「化粧品の効能の範囲（56効能）」から動的生成、②医薬部外品と一般化粧品をマスターで区別、③投稿型コミュニティは MVP から外し、相談テンプレと学内検証のみ扱う、④推薦理由文はテンプレ運用で自由生成を制限、⑤Before/After画像は端末ローカル保存のみ、⑥利用規約に「医療行為ではない」を明記。開発工程の節目で教員・薬剤師資格保有者・公的窓口に確認を依頼します。

**Q15. 沖縄ローカル要素は本当に必要？**

**A. **沖縄みらいAI&IT専門学校の卒業制作という背景を活かし、地域性を盛り込むことで、(1)中間発表時のストーリーが強くなる、(2)沖縄特有の気候（高湿度・強紫外線）に対する男性スキンケアの提案ができる、(3)将来構想として地元理美容店との連携が拡張しやすい、というメリットがあります。MVPでは沖縄要素は控えめに、将来構想として明示する設計です。

**Q16. 男性化粧品の市場規模が出典で違うのはなぜ？（v4.2 新設・R11 対応／v5.1 で発表日と富士経済を明記）**

**A. **本企画書に併記している「インテージSCI 497億円（2025年2月4日発表）」「矢野経済 1,330億円（2025年11月発表）」「TPC 1,421億円／2025年見込1,461億円（2025年6月発表）」「富士経済 1,636億円見込（2025年7月23日発表）」は、いずれも2024年〜2025年の数字ですが**集計軸が異なる**ため一見乖離して見えるだけで、相互に否定し合うものではありません。インテージSCIは個人パネルベースの「家庭内消費の購入金額推計」、矢野経済はメーカー出荷金額ベース（医薬部外品・輸入品含む）、TPCはメンズコスメというカテゴリ定義に芳香・制汗・においケアなどを含む広めの集計、富士経済はさらにヘアケア・ヘアメイクまで含む最も広義の集計です。共通して言えるのは「市場規模は拡大基調」「特に基礎化粧品（スキンケア）・メンズ整肌料・オールインワンが成長を牽引」という事実で、企画の前提（市場が拡大しているメンズ向けスキンケアにアプリでアプローチする）は4 出典いずれも支持しています。さらに、市場拡大の構造は「購入率（30.4%→33.2%、+2.8pt）」と「購入金額（1,869円→3,131円、1.7倍）」の**人口×単価の二重成長**であり、特に20代男性は購入率46.1%・年間4,615円で全年代トップ。プライマリ層を15〜35歳に置く本企画の妥当性をデータが裏付けます。

**Q17. オルビスミスター向けに「肌カ.ル.テ」が拡張されたら、本企画は不要にならないか？（v4.2 新設・R7 対応）**

**A. **想定されるシナリオであり、卒制提出後の継続シナリオで対応します。オルビスの「肌カ.ル.テ」（23 問 × 33 コース、有人チャット、460 万 DL）は既に女性ターゲットでは強力ですが、現状はオルビスミスター（男性向けブランド）専用のアプリには統合されていません。仮にオルビスミスターが肌カ.ル.テ的な機能を実装した場合、本企画の優位点は (1)中立的に他社製品も含めて推薦する点、(2)髭剃りケアを独立機能として強調する点、(3)推薦アルゴリズムにアフィリエイト手数料率を反映しないという中立性の担保、の3点に絞られます。本企画書 4 章の競合表でオルビス肌カ.ル.テを明示し、Q&A でも想定問答できる体制を整えています。
