# UIデザインガイドライン v1.0

**プロジェクト：** 田島組 卒業制作（男の身だしなみアプリ）
**関連：** [画面設計書](../design/画面設計書_v1.0.md)・[アクセシビリティ要件定義書](./アクセシビリティ要件定義書_v1.0.md)
**ステータス：** ドラフト（基盤CSS `app/css/style.css` に準拠）
**テイスト：** ソフト・親しみ（initiate-friendly）— 初心者が身構えない暖色基調

> 配色・文字・余白・コンポーネントの基準。**新規UIは必ずこのトークンを使い、色や角丸を勝手に増やさない。**

---

## 1. カラートークン（`:root` 実装済み）

| 用途 | 変数 | 値 |
| --- | --- | --- |
| 地（背景） | `--bg` | `#FFF7EE`（暖色クリーム） |
| 面（カード） | `--surface` | `#FFFFFF` |
| 本文 | `--text` | `#2B2622`（真黒は使わない） |
| 補足 | `--muted` | `#6E6359` |
| 主アクセント面 | `--orange` | `#F0822E` |
| ボタン地 | `--orange-cta` | `#D9701F`（白文字は14px太字以上のみ） |
| 小さいオレンジ文字 | `--ink-orange` | `#9E4E0E` |
| 成功・完了面 | `--green-strong` | `#4E9A48` |
| 小さい緑文字 | `--ink-green` | `#2F6A2C` |
| 罫線 | `--line` | `#EAD9C8` |
| 罫線（強） | `--line-strong` | `#D6BDA7` |
| やわらか面（淡オレンジ） | `--soft` | `#FFF0DF` |

**色の鉄則**：オレンジ＝行動／進捗、緑＝完了／肯定。それ以外の意味で色を使わない。

**別名（エイリアス）**：既存クラスが参照する別名も `:root` に定義済み。`--ink`＝`--text`／`--border`＝`--line-strong`／`--line-soft`＝`--line`。新規UIは意味に合う変数（原則 `--border`・`--line`）を使う。

## 2. 角丸・余白・モーション

| 種類 | 変数 | 値 |
| --- | --- | --- |
| カード角丸 | `--r-card` | `16px` |
| ヒーロー角丸 | `--r-hero` | `20px` |
| ボタン角丸 | `--r-btn` | `14px` |
| 影（標準・浮き） | `--shadow` | `0 16px 40px rgba(83,54,28,.14)` |
| 影（弱・接地） | `--shadow-soft` | `0 8px 24px rgba(83,54,28,.09)` |
| 標準イージング | `--ease` | `cubic-bezier(.4,0,.2,1)` |

- ステージ最大幅 `980px`、スマホシェル幅 `min(392px,100%)`。
- アニメは `transform` / `opacity` 中心（レイアウトを動かさない）。
- 影は上記2種のみ使う（部品ごとに影を自作しない）。
- **余白トークンは未定義**（現状は各所で直値指定）。`--space-*` の導入は MVP 後の整理課題（[提案-U6/#71] のトーン統一と併せて検討）。今は既存の余白リズムに合わせる。

---

## 3. タイポグラフィ

- 本文：`Noto Sans JP` / line-height `1.6`。数字は `Inter`（`tnum`）。
- 見出しは太く大きく（`font-weight:900`）、本文との**スケール差**で階層を作る。
- 最小フォント：補足12px以上（白/クリーム上でAAを満たす色のみ）。

---

## 4. 主要コンポーネント

| 部品 | クラス | 用途 |
| --- | --- | --- |
| カード | `.card` / `.qcard` | 情報のまとまり |
| 選択肢チップ | `.chip`（`aria-checked`） | 初回チェックの回答 |
| 主ボタン | `.cta`（dock固定） | 画面の主行動 |
| ゴーストボタン | `.ghost-btn` | 副次行動 |
| 比較表 | `.compare` | 商品横並び比較 |
| トースト | `.toast` | 一時的な確認通知 |
| 下シート | `.sheet` | 用語解説 |

- 状態は `hover / focus-visible / active / aria-checked / disabled` を必ず用意（[アクセシビリティ要件](./アクセシビリティ要件定義書_v1.0.md)）。

---

## 5. やらないこと

- 真黒（`#000`）・原色の多用、トークン外の色追加。
- 角丸・影・余白を部品ごとにバラバラにする。
- 装飾目的だけのアニメーション。
