# 利用統計アンケート設計 v1.0

**プロジェクト：** 田島組 卒業制作（男の身だしなみアプリ）  
**親：** [基本設計書 v1.0](../specs/基本設計書_v1.0.md) ／ [認証・データ保存方針書 v1.0](./認証・データ保存方針書_v1.0.md)  
**関連：** Issue #44 [p6a] デモシナリオ・発表資料 ／ [提案-D3] 匿名利用統計の収集  
**ステータス：** ドラフト（村上レビュー待ち）  

> 卒業発表での定量的なエビデンス確保（「n=◯人で検証した」等の数値説明）を目的に、
> 外部アンケートツール（Googleフォーム等）を用いてアプリ利用者の匿名統計・評価を収集するための仕様案。

---

## 1. 目的と背景

本アプリの卒業発表（8月末公開）において、単なる機能紹介にとどまらず**「実際の利用者に使ってもらい、どのような効果や評価が得られたか」**を定量データ（数値・グラフ）として提示できるようにする。

- **達成したいゴール**：発表スライド（#44）で「n=◯人に試用してもらい、◯%のユーザーが習慣化の効果を実感」等の定量的な検証成果を発表できる状態を作る。
- **収集方法**：アプリ外の外部フォーム（Googleフォーム／Microsoft Form等）による**任意・完全匿名の自己申告アンケート**。

---

## 2. プライバシー方針（#84）との整合性

[認証・データ保存方針書 v1.0](./認証・データ保存方針書_v1.0.md)（および Issue #84 プライバシーポリシー）で定めた**「ログイン不要・ローカル完結・センシティブ情報のサーバ非送信」**原則を厳守する。

| 項目 | アプリ内通信（テレメトリ） | 本アンケート（外部フォーム） |
| --- | --- | --- |
| **自動送信機能** | **一切実装しない** | なし（ユーザーによる手動送信） |
| **データ保持方針** | 端末内（IndexedDB / localStorage） | Googleフォーム等の集計基盤 |
| **回答の任意性** | - | **完全任意**（アプリ利用の必須条件にしない） |
| **個人識別性** | なし | **完全匿名**（氏名・メールアドレス・IP等の収集不可） |

> **注記**：アプリ内部からバックグラウンドで診断結果やログを自動送信する機能は、ローカル完結方針に反するため**採用しない**。あくまで外部アンケートでの自己申告収集とする。

## 4. 集計軸と発表資料（#44）での活用イメージ

収集した回答は集計の上、発表用スライド（#44 デモシナリオ・発表資料）にグラフ・定性データとして掲載する。

| 集計項目 | 発表資料でのビジュアル表示イメージ |
| --- | --- |
| **検証規模** | 「検証人数：`n=◯人`（試用モニター）」を大文字で強調 |
| **診断タイプ分布** | 診断結果のタイプ別割合（円グラフ） |
| **満足度・効果実感** | 「習慣化に役立つと回答した割合：◯%」（棒グラフ / ゲージ） |
| **機能別評価** | 「最も評価が高かった画面：S2改善ロードマップ（◯%）」 |
| **定性的な声** | スライド下部に「ユーザーの声（Q7より抜粋）」として吹き出し掲載 |

## 5. アプリ内誘導（外部リンク設置）の検討

アプリ内からアンケートに気づきやすくするため、アプリ内に外部フォームへのリンクボタンを配置することを検討する。

- **設置箇所案**：
  1. **設定/メニュー画面**（またはヘッダー/フッター）：「卒業発表アンケートにご協力ください（外部サイト）」ボタン
  2. **記録完了画面（S4）**：チェック達成時のモーダル内に「フィードバックを送る」リンク
- **実装方針**：
  - 単なる `<a>` タグ / `window.open` による外部Googleフォームへのリンク設置のみ（トラッキングコード等は含めない）。
  - 本アンケート仕様案が村上レビューで合意された後、**別途小Issue（UI実装タスク）として起票**する。
