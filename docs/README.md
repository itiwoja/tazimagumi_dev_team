# docs

設計書・議事録・ヒアリング記録などの **ドキュメント置き場** です。

## ディレクトリ構成

| ディレクトリ | 内容 |
|------|------|
| `specs/` | 要件・設計の確定ドキュメント群（相互に参照し合う中核資料） |
| `design/` | 基本設計書を親とする詳細設計（画面・DB・推薦・商品マスタ） |
| `guidelines/` | 横断ガイドライン（UI・薬機法・アクセシビリティ・コーディング規約・コンテンツ） |
| `dev/` | 実装方針（状態管理/ルーティング・データアクセス・認証/保存・テスト） |
| `schedule/` | スケジュール（ガントチャート） |
| `research/` | 市場調査・競合調査・ヒアリング記録・アンケート設計 |
| `presentation/` | 業界選択プレゼンの投影資料・台本・モックアップHTML |
| `archive/` | 旧版・ドラフト・作業メモ（履歴として残置） |
