## スライド3：この業界を選んだ理由

**「男性だけのチームで、自分たちがまず欲しいと思える1本を作る」**

1. **自分ごと化できる**：メンバー全員が男性。当事者として課題に共感できる
2. **市場が伸びている**：メンズコスメ市場は2025年見込で **1,461億円**（2024年比102.8%、TPC）
3. **既存サービスの隙間がある**：女性向けアプリ（LIPS等）・自社誘導型（BULK HOMME等）の中間に、**男性専用×中立的推薦**の空白がある
4. **沖縄の地域特性**：高湿度・強紫外線で男性の肌負担が他県より大きい

→ 「適当に選んだ業界」ではなく、**自分たちが顧客であり、伸びていて、空白がある**業界。

## スライド5：業界の課題（4つの困りごと）

**市場は伸びているのに、ユーザーは置き去り。**

1. **何を買えばいいか分からない**
   選択肢爆発（メンズランキングだけで79アイテム超）／専門用語が難解
2. **男性特有の悩みに情報が薄い**
   髭剃り後の荒れ・皮脂多め・女性向け情報の流用では合わない
3. **続かない**
   効果が出るまで約28日／順序が分からず自己流で挫折
4. **相談できる相手がいない**
   男性同士で美容の話題はしにくい／店員・家族にも聞きにくい

## スライド6：なぜ既存サービスでは解けないのか

| 既存サービス | 強み | 抜け落ちている部分 |
|---|---|---|
| LIPS（肌タイプ×成分相性診断） | 1,000万人ユーザー、AI診断完備 | **女性主体・男性ターゲット浅い／髭剃りケア無し** |
| BULK HOMME（AI肌診断） | 高精度なAI解析 | **自社製品誘導／中立性なし** |
| オルビス肌カ.ル.テ | 23問診断＋有人チャット | **女性主体・男性は別ブランド扱い** |
| ドラッグストア | 実物が見られる | **棚を見ても初心者には判断不可能** |

→ 診断そのものは既に競合が強い。田島組は **「診断後の行動変換」**、つまり **今日買う候補・今夜やる順番・髭剃り前後の注意タイミング** まで落とす点で差別化する。

## スライド7：システム案（企画書MVPとの整合）

**男の身だしなみ、最初の一歩を一緒に決めるアプリ**

中間発表MVPで見せる体験：

```
① QR / URL / LINE経由でPWAを開く
   ↓
② 6タイプ入口 または 23問初期チェックで悩みを整理
   ↓
③ 6軸スコアからタイプ・複合タイプを判定
   ↓
④ 自分用「身だしなみロードマップ」生成
   ↓
⑤ 今日買う候補3点、今夜・明日の朝の順番を提示
   ↓
⑥ 髭剃り前後の注意タイミングを可視化
```

- **企画書の主役**：診断精度ではなく、**初心者が最初の行動に移れるロードマップ**
- **MVP範囲**：6タイプ入口／23問初期チェック／商品候補3点／朝夜ステップ／髭剃り前後の表示
- **実装方針（v5.3）**：React + Vite + TypeScript + Supabase。専用バックエンドは作らない
- **商品データ**：Supabase Postgres の `products` テーブルに30〜50 SKUを手動整備
- **卒制MVP外**：公開コミュニティ、楽天API本連携、OCR運用、習慣化グラフ

## スライド8：診断ロジックとの整合

**23問を6軸に点数化し、結果をロードマップへ変換する**

| 6タイプ | 診断ロジックの軸 | 出す提案 |
|---|---|---|
| テカリ・皮脂 | `S_oily` | 皮脂コントロール候補 |
| 乾燥・カサつき | `S_dry` | 高保湿候補 |
| ニキビ・肌荒れ | `S_inflam` | 低刺激・すこやかケア候補 |
| 髭剃り後の荒れ | `S_shave` | アフターシェーブ候補 |
| くすみ・エイジング | `S_aging` | 年齢に応じたお手入れ候補 |
| 何もわからない | `S_beginner` | 入門オールインワン候補 |

- 各軸は **0〜100点**。最高得点軸を第一タイプにする
- `S_beginner >= 60` の場合は、初心者タイプを優先して離脱を防ぐ
- 1位と2位の差が10pt以内なら **複合タイプ** として2候補まで提示
- 「治る」「効く」「安全性スコア」ではなく、**成分タグ・客観データ・56効能範囲内の表現**に限定

## スライド9：このシステムで解決できること

| 業界の課題 | 本システムでの解決 |
|---|---|
| 何を買えばいいか分からない | 6タイプ入口／23問初期チェックから**今日買う候補3点**を提示 |
| 男性特有の悩みに情報が薄い | **髭剃り前後のタイミング**をロードマップ内で独立表示 |
| 続かない | MVPでは朝夜ステップと簡易フィードバック、拡張で週次評価・再診断 |
| 相談できない | 拡張でFAQ・相談テンプレを用意。公開コミュニティはMVP外 |

**メリット**
- ユーザー：迷う時間を減らし「今日買うもの・今夜やること・明日の朝やること」が決まる
- 業界：男性スキンケア初心者層の市場参入ハードルを下げる
