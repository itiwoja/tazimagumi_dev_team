# 1. 業界の現状

**男性化粧品市場は、コロナ後の身だしなみ意識の高まりで急速に拡大している。2024年の男性化粧品全体市場は497億円、2019年比1.8倍に伸長（インテージ調べ）。一方で、男性自身は「何を選べばいいか分からない」状態のまま市場に放り込まれている。**

- **男性向けスキンケア商品は急増（オルビスミスター、バルクオム、UNO、NULL、DiNOMEN、Lab Series、Kiehl's メンズ等）。一方で、選択肢が多すぎて「結局どれを買えばいいのか」が分からない状態が深刻化**

- **ドラッグストアの男性向けコーナーも限定的で、棚を見て判断するのは経験者には可能だが初心者には不可能（村上の沖縄市内ドラッグイレブンでの体験：棚を見て判断できず、何も買わずに帰宅）**

- **「美容に詳しい人に聞ける環境」は、男性の場合 LINEオープンチャット・Instagram・YouTube・Reddit r/AsianBeauty などに分散しており、アプリ内で完結する初心者向けの中立的な相談先は乏しい**

- **沖縄特有の事情：高湿度・強紫外線・年間平均気温の高さにより、皮脂分泌が多い男性の肌負担が他県より大きい**

## 3.1 ターゲット再定義（v2.0 → v3.0 で絞り込み）

## 3.2 ターゲット共通の課題

- **美容用語が分からない（ヒアルロン酸、セラミド、ナイアシンアミドなどの成分名）**

- **自分の肌タイプ（乾燥/脂性/混合/敏感）すら把握していない**

- **続かない（効果実感まで肌のターンオーバー約28日、短期では「変化が見えない」）**

- **肌磨き・髭剃り後のケアの「順番」が分からない**

- **男性特有の肌悩み（赤み・かゆみ・吹き出物・乾燥肌・敏感肌・髭剃り起因炎症）への情報が分散**

- **相談できる環境がアプリ内にない（LINEオープンチャット・Instagramコミュニティへの離脱が必要）**

## 3.3 簡易ユーザー調査（v3.0で追加）

**「男性が美容を相談しにくい」という前提に根拠を持たせるため、5月中に20〜30代男性 10〜20人へGoogleフォームで5問の簡易調査を実施する。設問例：**

- **① 現在スキンケアをしているか（している／していない／時々）**

- **② していない場合の理由（面倒／何を買えばいいか分からない／必要を感じない／その他）**

- **③ 友人と美容の話をする頻度（よく／たまに／しない）**

- **④ 美容について相談したい相手（友人／家族／店員／プロ／誰でもいい／誰にもしたくない）**

- **⑤ 美容アプリを使ったことがあるか（はい／いいえ）**

**集計結果は中間発表のスライドに「実データ」として組み込み、企画の根拠を強化する。**

## 3.4 ユーザー獲得トリガーの定義

**「スキンケアで困っている男性」と「アプリを使う男性」は必ずしも一致しない。困っていても「面倒くさい」「どうせ分からない」で調べない層は、アプリストアで能動的に検索しない。本アプリが届くべき層に届くためには、アプリを開くきっかけ（トリガー）を明確にし、それに応じた認知導線を設計する必要がある。**

| **トリガー** | **具体例** | **刺さるアプローチ** |
| --- | --- | --- |
| **肌トラブルの可視化** | ひげ剃り後の赤み・ニキビが鏡で気になり始める | 「ひげ剃り後の荒れ」タイプを前面に出した訴求 |
| **他者からの指摘** | パートナー・友人に「肌荒れてない？」と言われる | 「言われてから始めた人向け」の導線設計 |
| **SNS・動画経由** | TikTok / YouTubeで「メンズスキンケア入門」を視聴 | 短時間で結論が出る⑥「とにかく始めたい」タイプへの誘導 |
| **毎日の痛み** | カミソリ負けが毎回続き、限界を感じる | 「ひげ剃りケアモード」を入口にしたLPや紹介文 |

**設計方針：本アプリは「美容アプリ」ではなく「身近な困りごとを即解決するツール」として認知させる。アプリ名・ストア説明文・SNS投稿いずれにおいても「美容」より「身だしなみ」「ひげ剃り」「肌荒れ」ワードを優先する。**

# 5. 業界の課題深堀

## 課題① 結局何を買えばいいのか分からない

- **商品が多すぎて選べない（マイベスト・LIPSのメンズランキングだけで79アイテム超）**

- **専門用語（ヒアルロン酸、セラミド、ナイアシンアミド、BHA、AHA等）が分からない**

- **自分の肌タイプを把握していないため、棚で迷う**

## 課題② 男性特有の肌悩みに対応した情報が少ない

- **髭剃り後の肌荒れ、皮脂分泌の多さなど、男性ホルモン由来の悩み**

- **赤み・かゆみ・吹き出物・乾燥肌・敏感肌・髭剃り起因炎症など、男性特有の症状群への情報が分散**

- **女性向けの情報を流用しても、男性の肌（水分量約半分、皮脂量2〜3倍）には合わない**

- **髭剃りで毎日肌に負担がかかり、刺激のある商品を選ぶと負担が蓄積**

## 課題③ 習慣化が難しい

- **「面倒くさい」「効果が見えない」で続かない**

- **スキンケアの順序や頻度が分からず、自己流で挫折**

- **効果が出るのが遅く（ターンオーバー約28日）、短期では成果が見えにくい**

- **カレンダー記録だけでは「行動」の蓄積は見えるが「成果」が見えず、虚無感に繋がる**

## 課題④ 相談できる相手がいない

- **男性同士で美容の話題はしにくい風潮が根強い**

- **美容部員やドラッグストア店員に聞きにくい（特に若年層）**

- **家族・パートナーへの相談もハードルが高い**

- **既存の相談環境はLINEオープンチャット・Instagram・Redditに分散**

# 6. ITで解決できるポイント

| **課題** | **ITによる解決アプローチ** |
| --- | --- |
| **何を買えばいいか分からない** | **6タイプ即決UI（直感選択）→ 詳細を望む場合は23問診断で肌タイプ・悩み・髭剃りスタイル・予算を特定し、ロジックで候補商品をマッチング** |
| **専門用語が分からない** | **成分名を「うるおいを与える成分」「肌をすこやかに保つ成分」など、薬機法56効能の範囲内で平易な表現タグに変換して表示** |
| **男性特有の悩みに非対応** | **男性専用の質問項目（ひげ剃り頻度・髭の濃さ・皮脂量・髭剃りタイミング・使用カミソリ）を診断に組み込み、男性ホルモンによる影響を加味した推薦** |
| **髭剃りで肌に負担がかかる** | **髭剃りケアモードで「髭剃り直後に刺激になりやすい成分」を可視化＋ルーティン図解で、刺激の少ない選び方をアドバイス** |
| **習慣化できない / 効果が見えない** | **週次の自己評価グラフ＋3ヶ月再診断比較＋ミニクエスト＋継続日数バッジで、行動と成果を多角的に可視化** |
| **相談相手がいない** | **学内クローズドのスレッド型コミュニティで匿名相談（卒制スコープ）。投稿者の肌タイプ・年代・髭の濃さが自動表示されるため「自分と似た属性の人」の声が見つけやすい。卒制提出後は機能を非公開アーカイブに** |

# 7. システム案の提案

## 7.1 コアコンセプト

| **「男のスキンケア、最初の1本を選ぶアプリ」**<br>**6タイプ即決 → 詳細診断 → 個別推薦 → 理由説明 → 購入導線 → 習慣化サポート → クローズドコミュニティ**<br>**までを一貫して提供し、「結局何を買えばいいの？」に明確な答えを出す。**<br>**薬機法56効能の範囲内で誠実な表現を貫き、長く使えるサービスとして設計する。** |
| --- |

## 7.2 コアフロー

**① 6タイプ即決選択 → ② （任意で）23問詳細診断 → ③ 推薦商品の提示 → ④ 「あなたが選ばれる理由」の説明 → ⑤ 朝/夜のステップ可視化 → ⑥ 習慣化サポート（拡張） → ⑦ コミュニティ（拡張）**

## 7.3 UI設計の核：2段階診断構造

**ユーザーの幅広さ（15〜49歳・初心者〜経験者）に対応するため、TOP画面で2段階の入口を設ける。**

### TOP画面：6タイプから直感選択（主訴ベース）

**参考UI：Garmin公式サイトの「あなたの目指す理想はどのタイプ？」型レイアウト。カード形式で6つのタイプを横並び表示し、ユーザーが「自分の一番気になる悩み」を選ぶ。複数該当する場合は23問詳細診断へ誘導。**

**6タイプの設計根拠：男性の肌悩みを「原因の軸」で網羅的に整理すると自然に6つに収束する。皮脂分泌（①）・水分不足（②）・炎症（③）・男性ホルモン×物理刺激（④）・加齢（⑤）の5つの実悩みに、どれにも当てはまらない完全初心者の受け皿（⑥）を加えた構成。なお毛穴の黒ずみ・開きは皮脂分泌過多が主因であるため①の推薦ロジックに内包する。**

| **#** | **主訴（キャッチコピー）** | **想定ユーザー** | **推薦内容** | **特記** |
| --- | --- | --- | --- | --- |
| **①** | **テカリ・皮脂が気になる** | **脂性肌（毛穴悩みを含む）** | **皮脂コントロールセット** | **—** |
| **②** | **乾燥・カサつきをなんとかしたい** | **乾燥肌** | **高保湿セット** | **—** |
| **③** | **ニキビ・肌荒れを防ぎたい** | **炎症・混合肌（プライマリ層に多い）** | **低刺激・鎮静ケアセット** | **—** |
| **④** | **ひげ剃り後の荒れを防ぎたい** | **髭剃り負担に悩む層** | **アフターシェーブセット** | **髭剃りケアモードへ直結** |
| **⑤** | **くすみ・エイジングが気になる** | **36〜49歳・加齢症状** | **年齢肌ケアセット** | **—** |
| **⑥** | **何もわからない、とにかく始めたい** | **完全初心者** | **入門オールインワン1本** | **迷ったらこれ** |

**各カードには次の情報を表示する：**

- **理想の肌のイメージ写真**

- **カラー区分け（タイプごとに色分け）**

- **推薦商品セット名**

- **特徴タグ（「敏感肌対応」「時短ケア」「〜3,000円」など）**

- **「複数気になる」ボタンを各カードに配置 → 23問詳細診断へ**

### 2段階構造の流れ

**【ライト層】TOP画面で6タイプから選ぶ → 即座に推薦商品が表示される（離脱率を最小化）**

**【ガチ層／複数悩み層】画面右下の「もっと詳しく診断する」または各カードの「複数気になる」ボタン → 23問の精密診断 → パーソナライズされた推薦**

| **このUI設計により、初見のユーザーも離脱せず使え、複数悩みを持つ層・本気の人にはより精密な推薦を提供できる。** |

## 8.2 拡張フェーズ（卒制提出までに実装目標）

### ⑦ 習慣化サポート（3層）

**男性スキンケアは効果実感まで1〜3ヶ月かかる。この期間を多角的に支える。**

- **▼長期軸（月〜3ヶ月）：自己評価グラフ（毎週5段階）、継続日数バッジ、3ヶ月再診断比較、写真ギャラリー（端末ローカル保存のみ、サーバ送信なし）**

- **▼中期軸（週単位）：ミニクエスト、達成バッジ、XP**

- **▼短期軸：パートナー限定共有（招待制1人、Before/Afterはこのチャネルのみ）**

| **設計思想：**<br>**「行動の記録」だけでなく「成果の可視化」「外部からの応援」を組み合わせる。**<br>**AIによる肌の絶対値スコアリングは精度・撮影条件のブレを考慮して採用せず、ユーザーの主観評価＋再診断比較という信頼性のある体験設計を優先。**<br>**写真は完全ローカル保存（IndexedDB）でプライバシー保護。** |
| --- |

### ⑧ 学内クローズドコミュニティ機能

**卒制スコープでは、コミュニティを学内クローズド（招待制 or 学籍認証）とし、卒制期間限定とする。卒制提出後は非公開アーカイブに移行。**

**コミュニティの価値定義：「男性が基礎的なスキンケアの疑問をためらわず聞ける場」。薬機法上の制約（効果体験談・Before/After公開の禁止）の範囲内でも、使い方・順番・使用感・買い物相談といった初心者の「身近な困りごと」は自由に話せる。同じ肌タイプ・年代・髭の濃さのユーザーが回答者になる構造が、LINEオープンチャットや Redditにはない「自分ごと感」を生む。**

- **スレッド作成→返信形式の掲示板**

- **カテゴリ（再定義）：**
  - **使い方・順番の疑問（「洗顔後すぐ保湿？」「乳液は必要？」）**
  - **使用感の感想（テクスチャ・香り・べたつき感など感覚的な感想のみ。効果効能の断言は不可）**
  - **ルーティン共有（朝夜のケア手順を公開してフィードバックをもらう）**
  - **買い物相談（「ドラッグストアで買える？」「コスパは？」）**
  - **雑談（肌の調子・ひげ剃りネタ）**
  - **Before/After は本人＋招待者だけのプライベートに限定、公開コミュニティには出さない**

- **「変化が感じられない」投稿への対処：効果不満の投稿はモデレーションでブロックするのではなく「ルーティン相談」カテゴリに誘導し、ケア手順の見直しとして建設的に受け止める設計にする**

- **投稿者プロフィール：肌タイプ・年代・髭の濃さは表示、名前・顔は非公開**

- **AI執筆補助：項目を埋めると AI が文章を整える（書いてくれるのではなく整える）**

- **モデレーション：NGワード／薬機法ワード警告／OpenAI Moderation API／通報／ブロック／診断完了必須**

# 10. 薬機法ガードレール（新設）

**化粧品を扱うアプリケーションのため、医薬品、医療機器等の品質、有効性及び安全性の確保等に関する法律（薬機法）と医薬品等適正広告基準を遵守する。本企画では以下のガードレールを企画段階で固定する。**

## 10.1 NG表現と OK 言い換えテンプレート

| **NG表現（使わない）** | **OK表現（言い換え）** | **根拠** |
| --- | --- | --- |
| **ニキビを治す／消す／治る** | **「肌を清潔に保つ」「（医薬部外品の場合）ニキビを防ぐ」** | **一般化粧品では治療効果不可** |
| **シミが消える／白くなる** | **「日焼けによるシミ・そばかすを防ぐ（医薬部外品）」「メーキャップ効果で肌を明るく見せる」** | **化粧品 56 効能範囲外** |
| **皮脂を抑える** | **「余分な皮脂を落とす」「さっぱりとした感触」** | **一般化粧品では「抑える」不可** |
| **毛穴改善／毛穴を引き締める** | **「毛穴の汚れを落とす」「キメが整い毛穴が目立ちにくい肌へ（印象範囲内）」** | **「毛穴改善」は56効能範囲外** |
| **効く／効果がある** | **「使用感が高評価」「同じ悩みのユーザーから選ばれている」** | **効能効果の保証は禁止** |
| **あなたに必ず合う／効果保証** | **「同じ肌タイプの方によく選ばれている」「相性を試してみる価値あり」** | **保証表現の禁止** |
| **No.1／日本一／最高** | **「楽天市場メンズスキンケア部門 〇月度ランキング1位」（客観データ明示）** | **最大級表現は客観データ必須** |
| **（化粧品の）使用前後比較画像をコミュニティ公開** | **本人＋招待者の完全プライベート機能のみ。公開コミュニティでは表示しない** | **使用前後画像は効能効果の暗示にあたる** |
| **（化粧品の）体験談・口コミでの効果謳い** | **「使用感の感想」「香りの印象」など使用感に限定。AI Moderation で効果効能ワードを警告** | **化粧品では体験談広告は原則禁止** |
| **医師・専門家・有名人の推薦** | **使用しない（卒制スコープでは想定なし）** | **薬機法 66 条 2 項の保証広告禁止** |
| **成分組成から「安全性スコア」「刺激スコア」を算出して提示** | **「この商品にはエタノールが含まれています」など成分の有無を事実として表示するのみ。評価・順位付けはしない** | **独自スコアによる安全性保証は効能効果の暗示にあたる** |

## 10.2 デザイン・実装レベルのガードレール

- **成分タグの表示は「化粧品の効能の範囲（56効能）」のリストから動的生成する。タグマスターを最初に整備**

- **医薬部外品（薬用化粧品）と一般化粧品は商品マスターで区別し、表示できる効能タグを分岐**

- **コミュニティ投稿の自動チェックリスト：「治る」「効く」「消える」「白くなる」「絶対」「100%」等のワードを検出→警告して投稿保留**

- **推薦理由文の生成テンプレートは事前に5〜10パターン用意し、AI 生成は「テンプレを埋める」運用に限定（自由生成は薬機法リスク）**

- **開発工程の節目で、教員・薬剤師資格保有者または公的相談窓口（都道府県薬務課等）に確認を依頼する計画を組み込む**

# 13. 質疑応答（想定 Q&A）

**Q0. スキンケアに関心のない男性がなぜこのアプリを使うのか？**

**A. **「スキンケアに関心がある男性」と「スキンケアに困っている男性」は別の層です。本アプリのターゲットは後者——困っているが何をすればいいか分からず、調べる気にもなれない層——です。この層がアプリを開くのは「美容への関心」ではなく、「ひげ剃り後の痛みが限界」「パートナーに肌荒れを指摘された」「鏡で自分のニキビが気になった」といった具体的なトリガーです。そのためアプリの訴求は「美容アプリ」ではなく「ひげ剃り後の荒れが気になるなら」「肌荒れをどうにかしたいなら」という困りごと起点の言葉で行います。アプリを開いた後は⑥「何もわからない・とにかく始めたい」タイプが即座に1本の答えを出す設計が、この層の離脱を防ぎます。

**Q1. 男性向けに特化する必要はあるのか？女性向けアプリで十分では？**

**A. **男性は皮脂分泌が女性の約2〜3倍多く、ひげ剃りによる肌負担も独自の課題です。さらに「美容について男性同士で話しにくい」という心理的バリアがあり、女性向けサービスでは取りこぼされている層が大きく存在します。男性専用にすることで、ターゲットの悩みに正面から応えられます。

**Q2. v2.0では「ブルーオーシャン」と書いていたが、競合は本当に少ないのか？**

**A. **v2.0の認識は誤りでした。gencos（メンズコスメ専門アプリ、肌タイプ診断あり、2023年〜）、LIPS（1000万人、メンズ独立ランキング有）、@cosme（Snow Beauty Mirror で肌診断）など競合は既に存在します。v3.0では「競合は存在するが、本企画の組合せ（日本人男性向け × 中立的推薦 × 髭剃りケア独立 × 6タイプ+23問の2段階診断）は未着手領域」と認識を更新しました。差別化は具体的な4軸で説明できます。

**Q3. すでに価格.comや楽天市場があるのに、なぜ新しいアプリが必要？**

**A. **既存のECサイトは「商品リスト」を提供しますが、「自分に合うものを選ぶ」プロセスはユーザー任せです。本アプリは診断によって「自分専用の答え」を提示することに特化しており、初心者の意思決定コストを大幅に下げます。

**Q4. 診断の精度はどう担保する？**

**A. **23問の質問を肌タイプ・悩み・髭剃りスタイル・生活習慣・予算など複数軸でスコアリングし、組み合わせで判定します。スコアリングロジックは別紙「診断ロジック設計書」で詳細設計し、薬機法に準拠した表現で結果を提示します。3ヶ月ごとの再診断で肌の変化を追跡し、推薦と前回比較レポートを自動更新する仕組みを設けます。

**Q5. 収益モデルは？「中立的推薦」とアフィリエイト収益は矛盾しないか？**

**A. **主にアフィリエイト収益（楽天市場など）を想定します。中立性を担保するため、推薦アルゴリズムにはアフィリエイト手数料率を反映させず、肌タイプ・悩み・予算のみを推薦の根拠とします。アフィリエイト収益はあくまで運営継続のための原資という位置づけを利用規約に明記します。将来的には有料プラン（詳細レポート、専門家相談など）も検討。

**Q6. 商品データはどこから集める？価格.com APIを使うのでは？**

**A. **価格.com APIは2012年6月末で新規受付を終了しており、現在は利用できません。v3.0では「楽天市場API（2026年5月13日以降の新版、accessKey + Referer/Originヘッダー認証）」を主力とし、加えて自前の商品マスターDB（200〜300SKUを手動キュレーション）を整備します。成分情報は化粧品成分オンライン等のWeb DBから転記運用します。これにより、API依存度を下げて卒制の安定性を確保しています。

**Q7. 競合（gencos、LIPS、@cosme等）が出てきたらどう差別化する？**

**A. **本企画は競合との具体的差分を4軸で持っています：①6タイプ即決UI（gencosは韓国コスメ起点）、②髭剃りケア独立モード（他アプリは扱いが薄い）、③ライン使い→個別最適の卒業システム（中立性と習慣化の両立）、④男性向け表現設計（LIPSは女性主体）。中間発表時のQ&Aでも、この4軸で即答できる体制を整えます。

**Q8. 開発スコープは？11月中間発表で何を見せる？**

**A. **MVPとして以下を実装します：①6タイプTOP画面、②23問詳細診断（スコアリング含む）、③商品推薦（200〜300SKUから）、④推薦理由の説明、⑤朝・夜のステップ可視化、⑥髭剃りケアモード（簡易版）。⑦習慣化サポート（自己評価グラフ・継続バッジ）と⑧学内クローズドコミュニティは拡張フェーズで卒制提出までに実装目標とします。

**Q9. なぜ「2段階診断（6タイプ選択 + 23問診断）」の構造にしたのか？また、なぜ6タイプなのか？**

**A. **まず6タイプの根拠について：男性の肌悩みを「原因の軸」で整理すると、皮脂分泌（テカリ）・水分不足（乾燥）・炎症（ニキビ・肌荒れ）・男性ホルモン×物理刺激（ひげ剃り荒れ）・加齢（くすみ・エイジング）の5軸に収束します。これに、どれにも当てはまらない完全初心者の受け皿を加えた計6タイプが、男性の悩みの入口を過不足なくカバーできる最小構成です。次に2段階構造の理由：ユーザー層が15〜49歳と幅広く、ITリテラシーやスキンケアへの熱量も大きく異なります。いきなり23問を出すと「面倒くさい」と離脱されるリスクが高い一方、6タイプだけでは精度が不足します。ライト層には直感で選べる入口を、複数悩み層・本気層には精密な23問診断を用意することで両方の層を取り込みます。Garmin公式サイトのウォッチ選択UIなど、実証済みのUXパターンを参考にしています。

**Q10. AIで肌画像を解析する案はなぜ採用しなかった？**

**A. **当初はAI画像解析で肌スコアを数値化する案を検討しましたが、(1)撮影条件（光量・角度・カメラ）のブレで数値が安定しない、(2)AIの精度が「肌の状態」より「光の状態」を測ってしまうリスク、(3)顔写真を外部APIに送ることへのプライバシー懸念、の3点から採用を見送りました。代わりに、ユーザー自身の主観評価（毎週5段階）と23問再診断の比較を組み合わせた信頼性のある体験設計を採用しています。

**Q11. 薬機法の制約がある中で、コミュニティに来る価値はあるのか？**

**A. **コミュニティの価値を「効果体験談を共有する場」ではなく、「男性が基礎的なスキンケアの疑問をためらわず聞ける場」と定義しているため、薬機法の制約は本質的な価値を損ないません。「洗顔後すぐ保湿するの？」「乳液って必要？」「ドラッグストアで買えますか？」といった初心者の素朴な疑問は、薬機法の範囲内で自由に話せます。また投稿者プロフィールに肌タイプ・年代・髭の濃さを表示することで、「自分と似た属性の人の声が見つかる」体験が生まれ、LINEオープンチャットや Reddit にはない「自分ごと感」が差別化になります。誹謗中傷・薬機法違反の投稿に対しては、NGワードフィルタとOpenAI Moderation APIで自動チェックし、断定的な効能表現は警告して投稿を保留します。「変化が感じられない」という不満投稿はブロックせず「ルーティン相談」カテゴリに誘導し、建設的な改善相談として受け止めます。

**Q12. ライン使い推奨は「中立的推薦」と矛盾しないのか？**

**A. **ライン使いは「初心者の習慣化を支える選択肢の一つ」として提示します。推薦UIでは個別最適推薦とライン使い統一推薦の2方式を併記し、ユーザーが選択できる構造にすることで中立性を保ちます。さらに3ヶ月後の再診断で「個別最適化に卒業しますか？」と問いかけ、ユーザーの成長段階に応じて推薦方式を進化させるフェーズ制を採用しています。

**Q13. 髭剃りケアモードを独立機能にした理由は？**

**A. **ひげ剃り起因の肌負担は男性ホルモンに直結する男性特有の悩みであり、女性向けアプリには存在しない領域です。これを単なる悩みタグの一つとして埋もれさせず、独立モードとして強調することで、(1)他アプリとの明確な差別化、(2)毎日髭を剃る男性の利用頻度向上、(3)発表時の機能訴求力強化、の3つの効果を狙えます。

**Q14. 薬機法対応はどう担保する？**

**A. **本企画書の第10章「薬機法ガードレール」で、NG表現とOK言い換えテンプレートを企画段階で固定しています。具体的には：①成分タグは「化粧品の効能の範囲（56効能）」から動的生成、②医薬部外品と一般化粧品をマスターで区別、③コミュニティ投稿はNGワード検出で警告、④推薦理由文はテンプレ運用で自由生成を制限、⑤Before/After画像はプライベートのみ、⑥利用規約に「医療行為ではない」を明記。開発工程の節目で教員・薬剤師資格保有者・公的窓口に確認を依頼します。

**Q15. 沖縄ローカル要素は本当に必要？**

**A. **沖縄みらいAI&IT専門学校の卒業制作という背景を活かし、地域性を盛り込むことで、(1)中間発表時のストーリーが強くなる、(2)沖縄特有の気候（高湿度・強紫外線）に対する男性スキンケアの提案ができる、(3)将来構想として地元理美容店との連携が拡張しやすい、というメリットがあります。MVPでは沖縄要素は控えめに、将来構想として明示する設計です。
