# テスト仕様書 v1.0

**プロジェクト：** 田島組 卒業制作（男の身だしなみアプリ）
**関連：** [診断ロジック設計書 v1.1 §6](../specs/診断ロジック設計書_v1.1.md)・[推薦ロジック仕様書](../design/推薦ロジック仕様書_v1.0.md)・[アクセシビリティ要件定義書](../guidelines/アクセシビリティ要件定義書_v1.0.md)
**ステータス：** ドラフト

> 中間発表で**止まらずデモできる**ことを最優先に、テスト範囲と確認手順を定義します。
> ロジック（診断・推薦）は自動テスト、画面は手動チェックリスト中心。

---

## 1. テストの種類と対象

| 種類 | 対象 | 方法 |
| --- | --- | --- |
| 単体（ロジック） | 診断スコアリング／タイプ判定／推薦抽出 | 純粋関数の入出力を検証 |
| 結合（画面遷移） | ①→②→③→④の導線・データ受け渡し | 手動シナリオ |
| 受け入れ（デモ） | 中間発表の通しデモ | 手動・本番想定環境 |
| アクセシビリティ | A1〜A7要件 | 手動＋DevTools |

---

## 2. 診断ロジックの単体テスト（必須）

[診断ロジック設計書 §6](../specs/診断ロジック設計書_v1.1.md) のテストケースをそのまま検証する。

| ケース | 入力概要 | 期待結果 |
| --- | --- | --- |
| A | 20歳・皮脂多めの初心者 | タイプ① 単独 |
| B | 38歳・エイジング×髭剃り | タイプ④×⑤ 複合 |
| C | 25歳・未経験・悩み未言語化 | タイプ⑥（例外3a） |

- 追加観点：スコア100クリップ／Q3スキップ分岐／同点優先順位／複合フラグ（差≤10pt）。

---

## 3. 推薦ロジックの単体テスト

| 観点 | 期待 |
| --- | --- |
| 予算 `sub` | `budget==="sub"` のみ返す |
| 予算 `core` | core＋sub 全件が対象 |
| タイプ絞り込み | `type_tags` に対象タイプを含む商品のみ |
| 比較トレイ | 最大3点まで／成分は有無のみ表示 |

---

## 4. 画面遷移シナリオ（手動）

1. 初回チェック5問を回答 → 結果が表示される。
2. タブ②③④が初回完了前はロック、完了後に解放される。
3. ②→③で予算トグルが件数連動。③→④で記録が動く。
4. ④「もう一度」で①に戻り再診断できる。

---

## 5. アクセシビリティ確認

- A1 コントラスト／A2 キーボードのみ操作／A3 タップ44px／A5 reduced-motion／A7 aria-label。
- 詳細は [アクセシビリティ要件定義書 §4](../guidelines/アクセシビリティ要件定義書_v1.0.md)。

---

## 6. 薬機法・表現チェック

- 結果・商品・成分の文言に禁止表現が無いか（[薬機法準拠ガイドライン §2](../guidelines/薬機法準拠ガイドライン_v1.0.md)）。
- ディスクレーマーが②③の末尾に常時表示されるか。

---

## 7. デモ前チェックリスト（中間発表）

- [ ] ローカルデータのみで起動する（外部API非依存）
- [ ] 初回チェック→ロードマップが止まらず表示
- [ ] 商品候補・比較が表示される（30件以上整備済み）
- [ ] reduced-motion／文字大きめでも崩れない
- [ ] `console.log` が残っていない
