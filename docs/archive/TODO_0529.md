## 基本方針：作る順番

> **要件定義 → 設計書 → ガントチャート確定** の順で進める。
> 現状のガントチャートは「推定で作ったドラフト」。設計書が固まり次第、工数・担当・依存関係を見直して確定させる。

```
企画書 / 機能定義書 / 診断ロジック設計書 / 要件定義書 最小版（✅ 済）
   ↓
② 設計書を作る（画面・DB・システム）※要件定義書 最小版の4画面・6機能を基準に
   ↓
③ 設計が固まったらガントを「推定」から「確定」に更新
   ↓
④ 実装 → テスト → 中間発表（11月）
```

> 2026-06-16：[要件定義書 最小版](../specs/要件定義書_v1.0.md) を確定し、企画書・機能定義書を最小版（4画面：初回チェック／結果／商品比較／継続記録、6機能要件 REQ-01〜06）に揃えて全面改訂した。
