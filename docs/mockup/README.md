# Webモックアップ（v3.0 準拠）

田島組 卒業制作アプリ「男のスキンケア、最初の1本を選ぶアプリ」の **画面モックアップ** です。
企画書 v3.0（`docs/企画書_v3.0.md`）の MVP 機能を、frontend レーンが実装に入る前の **視覚仕様書** として静的 HTML に落とし込んでいます。

## 使い方

任意の HTML をブラウザで直接開くだけで閲覧できます。ビルドやサーバ起動は不要です。

```text
docs/mockup/index.html   ← 全画面のインデックス（ここから開くと便利）
```

## デザイン方向

- **Quiet Tech × 男性的エディトリアル**：落ち着いたネイビー＋ウォームベージュ。テンプレ感を排除。
- **2 段階のリズム**：6タイプは「カード即決」、23問は「1問1画面で集中」。
- **薬機法ガードレール準拠**：本モック内のコピーも v3.0 第10章の OK 表現テンプレートに従っています（「治る」「効く」「消える」を使用しない）。
- **モバイル基準 390 × 812**：iPhone 14 想定。デスクトップではフレーム表示でレビュー。
- **画像はプレースホルダ**：実商品画像・人物写真は使用せず、抽象的なグラデーション・SVG で代替。

## モックに含まれないもの

- **状態の永続化**：診断回答や記録はメモリ上のみ。リロードでリセット。
- **API 連携**：楽天 API・OpenAI Moderation API は呼び出さない。
- **実商品データ**：固有名詞は薬機法・景表法リスク回避のため使用していない（ダミー名で表現）。
- **アクセシビリティ詳細**：WCAG 2.1 AA 対応の文字大きめモード、色覚配慮は実装側で担保。
