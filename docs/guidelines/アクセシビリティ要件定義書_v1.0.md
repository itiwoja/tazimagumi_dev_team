# アクセシビリティ要件定義書 v1.0

**プロジェクト：** 田島組 卒業制作（男の身だしなみアプリ）
**親：** [基本設計書 v1.0 §7](../specs/基本設計書_v1.0.md) ／ **関連：** [UIデザインガイドライン](./UIデザインガイドライン_v1.0.md)・[テスト仕様書](../dev/テスト仕様書_v1.0.md)
**基準：** WCAG 2.1 AA を意識
**ステータス：** ドラフト（基盤CSS `app/css/style.css` に実装済みの方針を明文化）

> 「初心者でも迷わない」を支える最低限のアクセシビリティ要件。**実装時のチェックリストとして使う。**

---

## 1. 必須要件（MVPで満たす）

| # | 要件 | 実装の指針 |
| --- | --- | --- |
| A1 | コントラスト比 **4.5:1 以上**（本文）／3:1以上（大きい文字） | 白・クリーム面で再計算済みのトークンのみ使う |
| A2 | キーボード操作可能 | すべての操作要素は `button`/`a`。`:focus-visible` で枠表示 |
| A3 | タップ領域 **44px以上** | chip 56px・CTA 52px・budget 46px を維持 |
| A4 | 状態を色だけで伝えない | 選択は `aria-checked`＋チェック記号、進捗は数値も併記 |
| A5 | 動きを減らせる | `prefers-reduced-motion` でアニメ全凍結（実装済み） |
| A6 | 文字を大きくできる | 文字大きめモード（`prefs`）。`-webkit-text-size-adjust` 維持 |
| A7 | 適切なラベル | アイコンのみのボタンに `aria-label`（例：戻る「←」） |

---

## 2. スクリーンリーダー対応

- プログレスバーは `role="progressbar"` ＋ `aria-valuenow` を更新（実装済み）。
- 下シート（用語解説）は開いたら閉じるボタンへフォーカス移動、Escで閉じる。
- トーストは一時通知。重要情報はトーストだけに頼らない。

---

## 3. 文章のアクセシビリティ

- 専門用語は「○○ってなに？」で平易に補足（[コンテンツ設計書](./コンテンツ設計書_v1.0.md)）。
- 1文を短く。指示は「今日やること」のように具体行動で書く。

---

## 4. チェック方法

| 観点 | 方法 |
| --- | --- |
| コントラスト | ブラウザDevTools／コントラストチェッカー |
| キーボード | Tab・Enter・Escのみで全画面を操作できるか |
| reduced-motion | OS設定をONにして動きが止まるか |
| 読み上げ | スマホのTalkBack/VoiceOverで主要導線を確認 |

詳細手順は [テスト仕様書 §アクセシビリティ](../dev/テスト仕様書_v1.0.md)。
