朝・夜ステップ可視化「いつ・何を・なぜ」を 1 画面で

男性スキンケアの最大の壁は 「順番が分からない」 こと。朝 3 ステップ・夜 4 ステップを 1 画面で図解し、各ステップで何を使い、なぜそれを使うのかを一言で示します。持っている商品を登録すると、自分専用のルーティンに置き換わります。

— Spec
  • URL/routine
  • 朝ステップ3 (洗顔 / 化粧水 / 乳液+UV)
  • 夜ステップ4 (洗顔 / 化粧水 / 美容液 / 乳液)
  • マイ商品登録で専用ルーティン自動生成
— Design notes
  • 切替「朝 / 夜」タブで瞬時に切替
  • ステップ番号付きカード、縦の連結線
  • 理由各ステップに 1 文の説明（56 効能準拠）
  • 登録マイ商品登録 CTA を最下部に
