6タイプ即決 UI主訴で選ぶ — Garmin 風カードレイアウト

アプリ起動直後の画面。15〜49歳の幅広いユーザーに対応するため、最も気になる悩みを 6 カードから直感で選ぶ 構造にしています。複数の悩みを持つ層には「もっと詳しく診断する」で 23 問の精密診断に誘導します。

— Spec
  • URL/
  • 離脱率 KPI≦ 30%
  • 遷移先カードクリック → /recommend/[type]
  • 遷移先詳細 CTA → /diagnosis
  • 担当村上（共有コンポーネント・UI トークン）
— Design notes
  • レイアウト2列 × 3行のカードグリッド
  • カード内視覚 / タイプ番号 / コピー / 一言 / タグ
  • 色設計6 タイプで色相を変えて識別性を確保
  • 「複数気になる」各カード右下の小さなテキストリンク
