# S3比較仕様決定 v1.0

**決定日：** 2026-08-22  
**対象：** MVPの商品候補・比較（S3）  
**関連：** PR #197・Issue #61・`docs/design/推薦ロジック仕様書_v1.0.md` §4

## 決定

MVPは、**利用者が候補から最大3件を選んで比較する方式**とする。

候補の上位3件を自動で比較表へ入れる方式は採用しない。候補の並び順は推薦ロジックが決めるが、比較対象を決める操作は利用者に残す。

## 画面の振る舞い

- 候補カードは選択・解除でき、選択状態は `aria-pressed` で示す。
- 未選択または1件選択時は、比較表の代わりに「2〜3件選ぶ」案内を表示する。
- 2件または3件選択時は、選択した商品だけで比較表を再構築する。
- 4件目を選ぼうとした場合は選択状態を変更せず、「比較できるのは最大3商品までです」と案内する。
- 予算帯を切り替えた場合は、比較対象をクリアして新しい候補から選び直す。
- 比較軸は価格・容量・目的・成分タグの有無・違いの一言とし、成分は事実として有無だけを表示する。

## 理由

現行の正本である推薦ロジック仕様書 §4 と機能テストチェックリストは、比較トレイを「利用者が候補から最大3点選ぶ」と定義している。利用者の意図と比較対象を一致させ、候補の並び順を比較対象の自動決定と混同しないため、仕様どおりの選択式でMVPを確定する。

## 受け入れ条件

390px前後のスマホ幅で、候補カードの選択・解除、2件比較、3件比較、4件目の拒否、予算切替後のクリアを確認する。キーボード操作でも同じ選択状態を変更できることを確認する。
