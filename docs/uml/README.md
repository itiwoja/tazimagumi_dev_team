# UML 設計図一覧

このディレクトリには、男性美容アプリ「**MENS BEAUTY NAVI（仮）**」のモックアップを作る前段として、設計を共有するための UML を置いています。

すべて [Mermaid](https://mermaid.js.org/) 形式で書かれているため、**GitHub 上でそのまま図として表示されます**（プラグインや外部ツール不要）。VS Code でも `Markdown Preview Mermaid Support` 拡張を入れればプレビューできます。

## なぜ Mermaid なのか

- GitHub / VS Code / Notion でそのまま表示できる（PlantUML だと別途レンダラーが必要）
- テキストなので `git diff` で変更点が見える
- 未経験メンバーでも読み書きしやすい
