# 要件定義書 v1.0（最小版）

**プロジェクト：** 男の身だしなみアプリ ｜ 田島組 卒業制作
**目的：** 男性だけのチームが、自分たちが本当に使いたい身だしなみアプリを作る
**対象：** 身だしなみを始めたいが、何から始めるか分からない男性初心者
**方針：** 商品を選んで終わりにせず、開始から定着まで支える

## 1. このアプリで解決すること

身だしなみを始めたい男性が、最初の一歩で迷わず、買ったあとも続けられる状態を作る。男性だけのチームとして、まずは自分たちが毎日使いたいと思える体験を優先し、卒業制作のMVPでは範囲を絞る。

---

## 2. MVPの範囲

| 区分 | MVPでやること | MVPでやらないこと |
| --- | --- | --- |
| **開始** | 悩み・予算・生活習慣を確認し、今日から始める手順を提示する | 全ジャンルの美容知識を網羅する |
| **商品選び** | 初心者向けに最初の候補を少数提示し、違いを短く説明する | 外部API連携や大量SKUの自動収集 |
| **比較** | 価格帯・目的・成分タグなど、事実ベースで比較できるようにする | 安全/危険、効く/効かないの断定評価 |
| **定着** | 記録・再確認・リマインドで続けるきっかけを作る | SNS投稿、コミュニティ、サロン予約機能 |

---

## 3. 最小機能要件

| ID | 機能 | 要件 |
| --- | --- | --- |
| **REQ-01** | 初回チェック | 肌・髭剃り・髪・眉・予算・生活習慣を短時間で入力できる |
| **REQ-02** | ロードマップ | 診断結果から、今日買う候補、今夜やること、明日の朝やることを表示する |
| **REQ-03** | 商品候補 | MVPでは手動整備した30-50商品から、最初に検討する候補を提示する |
| **REQ-04** | 商品比較 | 複数商品を横並びで比較し、初心者でも違いが分かる一言を表示する |
| **REQ-05** | 成分タグ | 成分の有無など客観的な事実だけを表示し、安全性や効能の断定はしない |
| **REQ-06** | 継続支援 | 週次の自己評価、再確認、リマインドで続ける行動を促す |

---

## 4. 非機能要件・制約

| 区分 | 要件 |
| --- | --- |
| **法令・表現** | 薬機法に抵触しないよう、効能や安全性の断定表現を避ける |
| **プライバシー** | 写真などのセンシティブ情報はMVPではサーバ保存しない |
| **デモ安定性** | 中間発表では外部APIに依存せず、確認済みデータで動作させる |
| **保守性** | 商品データ、成分タグ、診断ロジックを差し替えやすく分離する |
| **使いやすさ** | 入力は短く、結果は3分以内に理解できる体験にする |

---

## 5. 成功条件

| 観点 | 成功条件 |
| --- | --- |
| **チーム内** | メンバー全員が、アプリをきっかけに何かしらの身だしなみ行動を始めている |
| **中間発表** | 初回チェックからロードマップ表示まで、止まらずにデモできる |
| **ユーザー体験** | 初心者が「何を買うか」「今日何をするか」を迷わず理解できる |
