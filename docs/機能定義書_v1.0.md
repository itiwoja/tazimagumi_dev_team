## 機能スコープ

### 🟥 MVP（11月中間発表・動作必須）

| # | 機能名 | 概要 |
|---|---|---|
| **F-01** | 6タイプ即決UI | 主訴ベース6カードから直感で選ぶTOP画面。男子向けデザイン・コピー |
| **F-02** | 23問初期チェック | 年齢・肌タイプ・悩み・ひげ剃り・予算を入力。予算選択肢に「〜1,500円」を含む |

| **F-05+06+10+16** | 商品推薦・詳細統合 | 概念ごとにおすすめ商品を提示。推薦理由（薬機法準拠）・1日あたりコスト・何日分か・複数商品比較を1画面に集約 |
| **F-08+11+13** | 使い方・ケア情報統合 | ミニマムルーティン（朝夜30秒）・カテゴリ別1回使用量目安・開封後使用期限目安を1画面に集約 |

## 設計上の重要方針

### ロードマップと商品推薦の分離
- **F-04（ロードマップ）**：「汚れ落とし」「化粧水」「乳液」など概念で表示
- **F-05+06+10+16（商品推薦）**：概念ごとに具体的な商品名・価格・理由を提示
- → ユーザーは「何をすればいいか」を先に理解してから「何を買うか」を決める

### 予算フィルター
- コアペルソナ：〜5,000円（3点セット）
- サブペルソナ：〜1,500円（ドラッグストア限定1本）
- 商品推薦画面で予算帯を切り替えられる設計

### 継続設計の方針
- 「継続システムを作ってもやらない人はやらない」
- → 継続機能に工数をかけるより **最初の一歩のハードルを極限まで下げる** ことを優先
- → ミニマムルーティン（朝夜30秒）を前面に出す

### 薬機法準拠
- 推薦理由は客観データ・成分タグ・56効能範囲内の表現に限定
- 「効く」「治る」「最適」などの断定表現は使用しない
- 使用期限は「一般的な目安」として表示し断定しない

### 髭剃りケアモード（F-07）の位置づけ
- MVPには含まないが **拡張フェーズで必須実装**
- 男性専用アプリの最大の差別化軸
- 競合（LIPS・オルビス等）が持っていない機能
- MVPでは診断の「髭剃りタイプ選択」で入口だけ作り、詳細は拡張で実装
