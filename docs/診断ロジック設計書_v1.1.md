## 1. 設計原則

本診断は「**医療的診断ではなく、自己申告に基づくレコメンドの根拠**」と位置づける。以下4つの原則で設計する。

1. **シンプルなルールベース**：機械学習や統計的推論は使わない。23問それぞれが6軸スコアに加点する明示的な配点表で完結させ、判定根拠が人間に説明できる状態を維持する。中間発表で「なぜそう判定したか」をスコア表で示せることを最優先する。
2. **6軸の独立性**：肌悩みの原因軸（皮脂・乾燥・炎症・髭剃り・加齢・初心者度）を独立にスコアリングし、最後に最高得点軸でタイプを決める。1問が複数軸に加点することは認めるが、軸同士の引き算（負の加点）はしない。
3. **薬機法準拠（v1.1 改訂・R3 連動）**：質問文と結果表示文に「治る」「効く」「消える」「保証」等の効能効果断定表現を一切含めない。結果表示は「あなたは〇〇タイプに該当する可能性があります（自己申告ベース）」「楽天市場メンズスキンケア部門 ○月度ランキング上位の商品」「あなたの肌タイプに推奨される成分（化粧品 56 効能の範囲内：うるおいを与える成分等）を含む商品」のように、**客観データ（出典付き）または成分タグ（56 効能の範囲内）**で表現する。v1.0 で「同じタイプの方によく選ばれている商品」と書いていた表現は、医薬品等適正広告基準で「他者への推薦」の暗示にあたるため v1.1 で削除した。
4. **離脱抑制**：プログレスバーと中間メッセージ（「あと10問」「肌タイプ判定セクション完了」等）で離脱率を抑える。23問の所要時間は3〜5分を想定する。

## 2. 6タイプとスコアリング軸の対応

| タイプ # | タイプ名 | 対応軸（変数名） | 推薦内容（企画書8.1③より） |
| --- | --- | --- | --- |
| ① | テカリ・皮脂が気になる | `S_oily` | 皮脂コントロールセット |
| ② | 乾燥・カサつきをなんとかしたい | `S_dry` | 高保湿セット |
| ③ | ニキビ・肌荒れを防ぎたい | `S_inflam` | 低刺激・鎮静ケアセット |
| ④ | ひげ剃り後の荒れを防ぎたい | `S_shave` | アフターシェーブセット |
| ⑤ | くすみ・エイジングが気になる | `S_aging` | 年齢肌ケアセット |
| ⑥ | 何もわからない、とにかく始めたい | `S_beginner` | 入門オールインワン1本 |

各軸は **0〜100点** のスコアを持つ整数値。23問全ての回答後に集計し、判定アルゴリズム（第4章）で最終タイプを決定する。

| セクション | 質問数 | 質問番号 | 主に加点される軸 |
| --- | --- | --- | --- |
| 基本情報 | 3問 | Q1〜Q3 | `S_aging`, `S_shave` |

| 悩み深堀り | 4問 | Q9〜Q12 | 全軸（主訴に応じて） |

| ケア環境 | 3問 | Q21〜Q23 | `S_beginner`, `S_aging` |

**配点上限の根拠**：各軸の理論最大値は、軸ごとに加点される質問の最大加点を合計し、100点に正規化する。たとえば `S_shave` は Q3+Q13+Q14+Q15+Q16+Q17 で理論最大 120pt 相当 → 100pt にクリップ。

## 4. 判定アルゴリズム

```
Step 1: 全23問の回答から6軸のスコア（S_oily, S_dry, S_inflam, S_shave, S_aging, S_beginner）を集計
Step 2: 各軸を 0〜100 にクリップ（min(score, 100)）
Step 3: 例外ルールを先に評価
  3a. S_beginner >= 60 → タイプ⑥（初心者）に確定 ※経験不足を最優先で受け止める
  3b. 全軸の最高スコアが 30 未満 → タイプ⑥（初心者）に強制振り分け ※どの軸も決定打がない場合の受け皿
Step 4: 最高スコアの軸 = 第一タイプ
Step 5: 同点の場合の優先順位
  S_shave > S_inflam > S_oily > S_dry > S_aging > S_beginner
  （理由：男性特有性が高く、毎日の負担が積み上がる髭剃り起因 > 肌トラブルの実害 > 多数派の皮脂悩み > 乾燥 > 加齢 > 初心者）
Step 6: 第一タイプと第二タイプのスコア差が 10pt 以内 → 「複合タイプ」フラグを立てる
  例：S_oily=68, S_shave=62 → 「皮脂タイプ × 髭剃りタイプ」の複合提案
  推薦UIでは両方のセットを並列表示し、ユーザーに最終選択させる
Step 7: タイプ判定結果と、判定根拠（軸別スコア + 上位3軸の質問貢献度）を返す
```

### 4.1 例外ルールの設計意図

- **3a (S_beginner >= 60)**：経験レベル（Q21）と1日にかけられる時間（Q22）が極端に低いユーザーは、たとえ皮脂や乾燥のスコアが高くても「3ステップケアを提案されたら離脱する」層と想定。タイプ⑥の入門オールインワン1本に振り分けることで「最初の1本を選ぶ」というアプリの中核体験を守る。
- **3b (最高スコアが30未満)**：23問全てに「特に気にならない」「普通」と答えるユーザーは、まだ自分の悩みを言語化できていない状態。専門用語で4タイプに振り分けるより、入門タイプ⑥で習慣化を支援する方が継続率が高いと仮定。

### 4.2 同点優先順位の根拠

```
S_shave > S_inflam > S_oily > S_dry > S_aging > S_beginner
```

- **S_shave 最優先**：男性特有の悩みで、女性向けアプリでカバーされない領域。本アプリの差別化軸でもあり、髭剃り後のケアが必要な状態を別タイプに吸収させない（v1.1 で「髭剃り起因の悩み」表現を「髭剃り後のケアが必要な状態」に統一・R8 連動）。
- **S_inflam 2位**：炎症・赤み・ニキビは「我慢している不快症状」であり、ユーザー満足度への影響が最も大きい。
- **S_oily 3位**：プライマリ層（15〜35歳）の最多悩み。デフォルト的に振り分けても外しにくい。
- **S_dry 4位**：実害は出ているが、保湿で改善しやすく緊急度はやや低い。
- **S_aging 5位**：セカンダリ層（36〜49歳）の関心軸。プライマリ層には優先順位を下げる。
- **S_beginner 最後**：例外ルール3aで吸収済みなので、同点ルートでは最後に置く。

## 5. 23問の質問設計

各質問は以下の表記で記載する：

```
Q番号: 質問文
- 選択肢A → スコア加点（軸: +N点）
- 選択肢B → スコア加点（軸: +N点）
[補足] UI上の注記、スキップ条件など
```

### 5.1 セクション1：基本情報（Q1〜Q3）

**Q1: あなたの年齢層を教えてください。**
- 15〜19歳 → なし
- 20〜25歳 → なし
- 26〜35歳 → `S_aging +10`
- 36〜45歳 → `S_aging +30`
- 46歳以上 → `S_aging +50`, `S_dry +10`

**Q2: 性別を教えてください（確認）。**
- 男性 → 通常進行
- それ以外 → 「本アプリは男性向け設計ですが、参考としてご利用いただけます」のメッセージ表示後に通常進行
- スコア加点なし（分岐用のみ）

**Q3: ひげ剃りの頻度を教えてください。**
- 毎日 → `S_shave +30`
- 週3〜5回 → `S_shave +20`
- 週1〜2回 → `S_shave +10`
- ほぼ剃らない／脱毛済 → `S_shave +0`、Q13〜Q17を**スキップ**してQ18へジャンプ
- ひげが生えない → `S_shave +0`、Q13〜Q17を**スキップ**してQ18へジャンプ

[補足] Q3でスキップ条件に該当した場合、髭剃りスタイル5問を飛ばすことで離脱を抑制する。残り18問になり所要時間が短縮される。

### 5.2 セクション2：肌タイプ判定（Q4〜Q8）

**Q4: 朝、洗顔して30分後の肌の状態に最も近いものは？**
- 全体的にベタつく・テカる → `S_oily +30`
- 額や鼻だけテカる（部分的） → `S_oily +15`, `S_dry +10`
- 全体的にかさつく・つっぱる → `S_dry +30`
- ヒリつく・赤みが出る → `S_inflam +30`
- 特に何も感じない → `S_beginner +10`

**Q5: 季節による肌の変化は？**
- 夏に特にテカる → `S_oily +10`
- 冬に特にかさつく → `S_dry +15`
- 季節の変わり目に荒れる → `S_inflam +20`
- 季節を問わず常に調子が悪い → `S_inflam +15`, `S_dry +10`
- あまり変わらない → `S_beginner +5`

**Q6: 毛穴の状態について。**
- 黒ずみが目立つ → `S_oily +25`
- 開いている感じがする → `S_oily +15`
- 鼻のあたりだけ目立つ → `S_oily +10`
- 気にならない → なし

**Q7: 額・鼻（Tゾーン）の油分は？**
- とても多い → `S_oily +25`
- 多い → `S_oily +15`
- 普通 → なし
- 少ない・乾く → `S_dry +10`

**Q8: 頬・あご（Uゾーン）の状態は？**
- かさつく・粉ふきする → `S_dry +25`
- 油分が多い → `S_oily +15`
- 赤みがある → `S_inflam +20`
- 普通 → なし

### 5.3 セクション3：悩み深堀り（Q9〜Q12）

**Q9: 一番気になる肌悩みは？（複数選択可、各+15）**
- テカリ・皮脂 → `S_oily +15`
- 乾燥・カサつき → `S_dry +15`
- ニキビ・吹き出物 → `S_inflam +15`
- 髭剃り後の荒れ → `S_shave +15`
- くすみ・トーンの暗さ → `S_aging +15`
- シワ・たるみ → `S_aging +20`
- 毛穴の黒ずみ → `S_oily +10`
- 赤み・ヒリつき → `S_inflam +20`
- 特にない → `S_beginner +15`

[補足] 複数選択可。最低1つは選択必須。「特にない」を選んだ場合は他の選択肢を選択不可（排他）。

**Q10: その悩みは、いつから感じていますか？**
- 最近（1〜3ヶ月以内） → なし（直近の状態をQ4〜Q9で既に反映）
- 半年〜1年前から → Q9で選んだ各悩みの軸に `+5`
- 何年も継続している → Q9で選んだ各悩みの軸に `+10`
- 子供の頃から → `S_inflam +10`（アトピー等の体質傾向）

**Q11: ニキビ・赤みが出る主な場所は？**
- 額・Tゾーン中心 → `S_oily +10`
- 頬中心 → `S_inflam +10`
- 顎・口周り中心 → `S_shave +10`
- 全体に出る → `S_inflam +15`
- 出ない → なし

**Q12: 悩みの強さ・頻度は？**
- 毎日のように悩む → `S_inflam +15`
- 月に数回 → `S_inflam +5`
- 季節限定で気になる → Q9で選んだ軸に `+5`
- たまに気になる程度 → なし
- ほとんど気にならない → `S_beginner +5`

### 5.4 セクション4：髭剃りスタイル（Q13〜Q17）

[補足] Q3で「ほぼ剃らない／脱毛済／ひげが生えない」を選んだ場合はセクション4全体をスキップしてQ18へ。

**Q13: 髭剃り後の赤みのタイミングは？**
- 剃った直後すぐ出る → `S_shave +30`, `S_inflam +15`
- 数時間後に出る → `S_shave +20`
- 翌日に出ることがある → `S_shave +10`
- 特に赤みは出ない → なし

**Q14: 主に使うカミソリの種類は？**
- T字カミソリ（多刃） → `S_shave +10`
- 電気シェーバー → `S_shave +5`
- I字カミソリ（クラシック・両刃） → `S_shave +15`
- 脱毛器を使用 → `S_shave +0`
- 医療脱毛済 → 該当する場合Q3で既にスキップ判定済

**Q15: ひげの濃さは？**
- 濃い・剛毛 → `S_shave +20`
- 普通 → `S_shave +10`
- 薄い → `S_shave +5`
- ほとんど生えない → 該当する場合Q3で既にスキップ判定済

**Q16: ひげ剃りの主な部位は？**
- 顎・口周りのみ → `S_shave +5`
- 顎・口周り＋頬の一部 → `S_shave +10`
- 全顔（広範囲） → `S_shave +15`
- 顔以外（首・胸・足など）も含む → `S_shave +20`

**Q17: ひげを剃るタイミングは？**
- 朝のみ → `S_shave +10`
- 夜のみ → `S_shave +5`
- 朝・夜の両方 → `S_shave +15`
- 不定期 → `S_shave +5`

### 5.5 セクション5：生活習慣（Q18〜Q20）

**Q18: 平均睡眠時間は？**
- 5時間未満 → `S_inflam +10`, `S_aging +10`

- 8時間以上 → なし

**Q19: 食生活で当てはまるものは？**

- 野菜中心 → なし

**Q20: 運動の頻度は？**
- ほぼ毎日 → なし
- 週2〜3回 → なし
- 週1回程度 → なし

### 5.6 セクション6：ケア環境（Q21〜Q23）

**Q21: 現在のスキンケア経験レベルは？**
- 全くやったことがない → `S_beginner +30`

- 化粧水まで使っている → `S_beginner +15`
- 化粧水＋乳液（または保湿） → `S_beginner +5`

**Q22: スキンケアに1日で使える時間は？**
- 30秒以内（オールインワンが好み） → `S_beginner +10`
- 1〜3分 → `S_beginner +5`

- 5分以上かけてもよい → なし

**Q23: スキンケアの月間予算は？**
- 〜1,500円 → `S_beginner +10`
- 1,500〜3,000円 → なし
- 3,000〜5,000円 → なし
- 5,000〜10,000円 → `S_aging +5`
- 10,000円以上 → `S_aging +10`

| Q6 | 黒ずみが目立つ | `S_oily +25` |

### ケース C：25歳、スキンケア未経験、悩みが言語化できていない

| 質問 | 回答 | 加点 |
| --- | --- | --- |
| Q1 | 20〜25歳 | なし |
| Q3 | 週1〜2回 | `S_shave +10` |
| Q4 | 特に何も感じない | `S_beginner +10` |
| Q5 | あまり変わらない | `S_beginner +5` |
| Q9 | 特にない | `S_beginner +15` |
| Q12 | ほとんど気にならない | `S_beginner +5` |
| Q21 | 全くやったことがない | `S_beginner +30` |
| Q22 | 30秒以内 | `S_beginner +10` |
| Q23 | 〜1,500円 | `S_beginner +10` |

**集計**：`S_beginner=85`, `S_shave=10`, 他<5

**判定フロー**：
- Step 3a: `S_beginner=85 ≥ 60` → **タイプ⑥ 強制振り分け**

**最終結果**：タイプ⑥「入門オールインワン1本」を推薦。「まず3週間続けてみる」というメッセージを添える。

## 7. 複合タイプ時の推薦ロジック

第一タイプと第二タイプのスコア差が10pt以内の場合、UI上で以下のように表示する：

```
[結果画面]
あなたは「タイプ④ 髭剃り後の荒れ」と「タイプ⑤ くすみ・エイジング」の傾向がありそうです。

▼ メインの推薦：アフターシェーブセット（タイプ④）
[商品カード3点]

▼ サブの推薦：年齢肌ケアセット（タイプ⑤）
[商品カード3点]

▼ あなたへの提案理由
ひげ剃り後のケアが必要な状態と、年齢に応じたお手入れの両方の傾向が
見られたため、両方のケアセットを提案しています。
最初はメインの推薦から1本ずつ試すのがおすすめです。
```

**複合タイプの上限**：第二タイプまでに限定する（第三タイプ以降は表示しない）。3タイプ以上を並列表示するとユーザーが選択不能になるため。

**複合タイプの例外**：タイプ⑥（初心者）が第二タイプに来た場合は複合表示せず、第一タイプ単独で推薦する（初心者向け推薦と他タイプの推薦が並ぶとユーザーが混乱するため）。

## 8. 法的ディスクレーマー

診断結果画面の **最下部に常時表示** する文言を以下に確定する。

```
【ご注意】
本診断は医学的な肌診断ではありません。ご回答内容に基づいて、楽天市場メンズスキンケア部門のランキング上位商品や、ご回答から推定される肌タイプに推奨される成分（化粧品の効能の範囲：56効能）を含む商品をご提案するものです。
肌の状態に不安がある場合は、皮膚科医・薬剤師など専門家にご相談ください。
本アプリは医療行為を行うものではなく、提案する商品の効能効果や安全性を保証するものでもありません。
独自スコアによる成分の安全性・刺激の強さの評価は行わず、成分の有無を事実として表示するに留めます。
```

（v1.1 改訂・R3＋R8 連動）：v1.0 で「同じ傾向の方によく選ばれている商品」と記載していた箇所を、医薬品等適正広告基準で禁止されている「他者への推薦」の暗示にあたるとの認識から、「ランキング上位商品」「肌タイプに推奨される成分（56 効能の範囲内）を含む商品」という客観データ＋成分タグ表現に置き換えた。また、独自スコアによる安全性評価を行わない方針を明文化した。

**配置ルール**：
- 診断結果画面の最下部（スクロール末尾）に固定表示
- フォントサイズは本文の85%、`var(--color-ink)`の50%透明度で控えめに
- 推薦商品カードを表示する全画面で常時表示

**追加表示**：
- 複合タイプ表示時には「複数の傾向が見られた場合、無理に1セットに絞らず、まず1〜2品を試すことをおすすめします」を追記
- タイプ⑥（初心者）表示時には「スキンケアの効果実感まで肌のターンオーバー（約28日）程度かかります。3週間継続後の再診断をおすすめします」を追記

## 10. 実装メモ（開発チーム向け）

### バックエンド（ひろと担当）

- 23問の回答 → 6軸スコアの集計関数を `DiagnosisService.calculateScores()` として実装
- 判定アルゴリズム（第4章）を `DiagnosisService.determineType()` として実装
- 入力値検証：Q9（複数選択可）は1〜9件、その他は1件選択必須
- 結果オブジェクト：`{ primaryType, secondaryType, isComposite, scores: { oily, dry, inflam, shave, aging, beginner }, topContributors: [...] }`

### フロントエンド（れん担当）

- 6セクションのプログレスバー実装
- セクション完了時の中間メッセージ（「肌タイプ判定セクション完了 / あと2セクション」等）
- Q3で「ほぼ剃らない／脱毛済／ひげが生えない」を選んだ場合のQ13〜Q17スキップ実装
- ディスクレーマーは結果画面の固定コンポーネントとして実装

### データ（たかと担当）

- 商品マスター側に「タイプ別タグ」（type1〜type6）を必ず付与
- 複合タイプ推薦のため、1商品に複数タイプタグを付けることを許可
