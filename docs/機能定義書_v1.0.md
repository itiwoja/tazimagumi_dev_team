## 機能スコープ

### 🟥 MVP（11月中間発表・動作必須）

| # | 画面 | 対応REQ | 概要 |
|---|---|---|---|
| **F-01** | 初回チェック | REQ-01 | 肌・髭剃り・髪・眉・予算・生活習慣を短時間で入力できる。入力は短く、離脱を防ぐ |
| **F-02** | ロードマップ（結果） | REQ-02 | 診断結果から「今日買う候補」「今夜やること」「明日の朝やること」を表示。商品名ではなく概念（汚れ落とし→化粧水→乳液）で手順を示す |

| **F-06** | 継続記録 | REQ-06 | 週次の自己評価・再確認・リマインドで続ける行動を促す |

## 設計上の重要方針

### ロードマップと商品推薦の分離（REQ-02 / REQ-03）
- **ロードマップ（F-02）**：「汚れ落とし」「化粧水」「乳液」など概念で表示
- **商品候補（F-03）**：概念ごとに具体的な商品名・価格・候補理由を提示
- → ユーザーは「何をすればいいか」を先に理解してから「何を買うか」を決める

### 事実ベースの比較（REQ-04 / REQ-05）
- 価格帯・目的・成分タグなど、**事実ベース**で比較できるようにする
- 成分は「有無」という事実のみを表示し、**安全/危険・効く/効かないの断定評価はしない**

### 予算フィルター
- コアペルソナ：〜5,000円（3点セット）
- サブペルソナ：〜1,500円（ドラッグストア限定1本）
- 商品候補画面で予算帯を切り替えられる設計

### 継続設計の方針（REQ-06）
- 「継続システムを作ってもやらない人はやらない」
- → 継続機能に工数をかけるより **最初の一歩のハードルを極限まで下げる** ことを優先
- → ミニマムルーティン（朝夜30秒）を前面に出す

### 薬機法準拠
- 推薦理由は客観データ・成分タグ・56効能範囲内の表現に限定
- 「効く」「治る」「最適」などの断定表現は使用しない
- 使用期限は「一般的な目安」として表示し断定しない

### デモ安定性
- 中間発表では外部APIに依存せず、確認済みデータ（手動整備の30-50商品）で動作させる
