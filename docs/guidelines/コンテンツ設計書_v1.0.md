**プロジェクト：** 田島組 卒業制作（男の身だしなみアプリ）
**関連：** [画面設計書](../design/画面設計書_v1.0.md)・[薬機法準拠ガイドライン](./薬機法準拠ガイドライン_v1.0.md)
**ステータス：** ドラフト

> 各画面の文言・トーン・推薦理由テンプレートを定義します。
> **初心者に語りかける／専門用語を避ける／断定しない**の3点が軸。

---

## 1. 文章トーン

- 一人の先輩が隣で教えるような、やわらかい敬体（「〜しましょう」「大丈夫です」）。
- 専門用語は使う前に1行で噛み砕く（例：「化粧水＝肌の水やり」）。
- 不安をあおらない。失敗しても続けられる前提で書く。
- 断定しない（[薬機法準拠ガイドライン](./薬機法準拠ガイドライン_v1.0.md)）。

## 3. 用語の言い換え辞書（抜粋）

| 専門用語 | やさしい説明 |
| --- | --- |
| 化粧水 | 洗ったあとの肌に水分を足す液。「肌の水やり」 |
| 乳液 | 水分にフタをして乾燥を防ぐもの |
| 皮脂 | 肌から出る油。多いとテカる |
| ターンオーバー | 肌が生まれ変わる周期（約28日） |

> 用語を増やすときは `main.js` の `TERMS` に追加（[コーディング規約](./コーディング規約_命名規則_v1.0.md)）。

---

## 4. 推薦理由テンプレート

- 単独タイプ：「ご回答から、〇〇タイプに該当する可能性があります。まずは△△から試すのがおすすめです。」
- 複合タイプ：「〇〇と△△、両方の傾向が見られたため、両方のケアを提案しています。最初は1本ずつ試すのがおすすめです。」
- 初心者タイプ：「まずはオールインワン1本から。3週間続けて、また診断してみましょう。」

> いずれも「効く・治る・最適」等を含めない。出典・成分タグ・自己申告ベースの言い回しで書く。
