# 男性化粧品市場リサーチレポート（2025年5月時点）

## 調査目的

プレゼン資料「業界の現状 — 数字で把握」セクションの掲載データを最新化するため、男性化粧品市場の市場規模・成長率・スキンケア実施率に関する最新の公開データを収集・検証した。

## サマリー

- 現スライド掲載の数値（497億円・4.9倍・3,131円）は **インテージが2025年2月に発表した2024年実績値** と完全一致しており、**データ自体は最新**である。
- 「2019年比」という比較年表記が古く見えるが、これは5年トレンドを示す指標であり、出典自体は最新発表（2025年2月）。
- 一方、スキンケア実施率「8割超／マイベスト調査」は出典の信頼性に課題があり、**2025年5月発表のくふう総研データへの差し替えを推奨**。
- 2025年見込み値（TPCマーケティングリサーチ発表）も補足データとして利用可能。

## 1. 男性化粧品市場規模

### 1-1. インテージ調査（基準データ）

| 項目 | 数値 | 備考 |
|---|---|---|
| 2024年 市場規模 | **497億円** | 前年比 114.8% |
| 2019年比 | **1.8倍** | 5年間の成長 |
| 男性基礎化粧品 市場規模 | 438億円 | 前年比 115.7% |
| カテゴリ別 2019年比 | 日焼け止め 2.0倍 / 基礎化粧品 1.8倍 / メイクアップ 1.3倍 | — |

- **出典**: 株式会社インテージ（全国消費者パネル調査 SCI）
- **発表時期**: 2025年2月
- **調査時期**: 2024年9月27日〜10月1日
- **サンプル**: 全国15〜79歳の男女 53,600人

調査機関により市場の定義範囲が異なるため、数値に差がある点に注意。

- **メンズ整肌料市場**: **326億円**（2024年比 +4.5%）見込み
- オールインワンタイプが市場をけん引、高機能化が進行
- 出典: TPCマーケティングリサーチ（2025年6月発表）

## 2. 男性美容液市場

- **2019年比 4.9倍** に拡大（インテージSCI）
- 男性基礎化粧品（438億円）の中で大きく伸びたカテゴリは **美容液・クレンジング・パック**
- 背景: 「化粧水・乳液の一歩先」へ進む高関与層の増加

## 4. 男性のスキンケア実施率

### 4-1. 現スライドの掲載値（要差し替え検討）

- 「20〜30代男性のスキンケア実施率 8割超」
- 出典: マイベスト調査（20〜30代男性50人）
- **課題**: サンプル数が50人と少なく、自社EC媒体の調査で信頼性が弱い

### 4-2. 推奨差し替え先データ

#### くふう総研調査（2025年5月）

- **男性のスキンケア実施率: 60.2%**（「意識高め」層から多数派へ）
- 使用しているスキンケア用品
  - 化粧水: 69.5%
  - 洗顔料: 61.8%
  - 乳液: 49.2%
- 6割以上の男性が「美容に関する悩み」を抱える
  - 悩みTOP3: シミ・くすみ / 抜け毛・薄毛 / ヒゲ
- 関心のある美容TOP3: スキンケア / 脱毛 / インナーケア
- **出典**: 株式会社くふうカンパニーホールディングス「くふう生活者総合研究所」
- **調査時期**: 2025年5月1日〜6日
- **サンプル**: 男性 1,280名

#### ネオマーケティング調査（2025年7月）

- 月間5,000円以上をスキンケアに投じる「高投資層」の割合
  - 10〜20代: 20.0%
  - 30代: 16.0%
  - 40代: 14.0%
  - 50代: 6.0%
- **サンプル**: 日常的にスキンケアを行う18歳以上男性 400名

#### プラネット調査（参考）

- 20代・30代男性の **半数が化粧水を使用**
- 洗顔料・化粧水ともに、20代よりも30代の方が使用率が高い

## 5. スライド改修の提案

### 案A（推奨・最小変更）: 比較年表記を更新

「2019年比 1.8倍」 → 「**2019→2024 で1.8倍**」または「**5年間で1.8倍**」と表記し、合わせて出典に「2025年2月発表」を明示する。データはそのまま使える。

### 案B（信頼性アップ）: スキンケア実施率を差し替え

| 現在 | 差し替え後 |
|---|---|
| 8割超 / 20〜30代男性のスキンケア実施率 / 出典: マイベスト調査 | **6割超** / 男性のスキンケア実施率 / 「意識高め層」から多数派の時代へ / 出典: くふう総研（2025年5月） |

または「化粧水使用率 **約7割**（69.5%）」として、使用率にフォーカスする案もあり。

### 案C（追加情報）: 2025年見込みを補足

「市場は今後も拡大基調」の根拠として、TPCマーケティングリサーチの **2025年メンズ整肌料 326億円（+4.5%）見込み** を脚注または補足カードに追加。
