# 薬機法準拠ガイドライン v1.0

**プロジェクト：** 田島組 卒業制作（男の身だしなみアプリ）
**親：** [基本設計書 v1.0 §8](../specs/基本設計書_v1.0.md) ／ **関連：** [診断ロジック設計書 v1.1 §8](../specs/診断ロジック設計書_v1.1.md)・[商品マスタ設計書](../design/商品マスタ設計書_v1.0.md)・[コンテンツ設計書](./コンテンツ設計書_v1.0.md)
**ステータス：** ドラフト
**一次管理：** たかと（表現チェックの最終確認）

> 結果・推薦・成分・記録の**すべての表示文言**が守るべき表現ルール。
> 原則：**断定しない／事実だけ書く／出典か成分タグで語る。**

---

## 1. 基本3原則

1. **効能効果を断定しない** — 「治る・効く・消える・最適・保証」等は使わない。
2. **成分は有無の事実のみ** — 安全/危険・刺激の強弱を独自評価しない。
3. **推薦理由は客観で語る** — 出典付きランキング、または56効能の範囲内の成分タグで表現。

---

## 2. 禁止表現 → 言い換え（早見表）

| ❌ 禁止 | ✅ 言い換え |
| --- | --- |
| ニキビが治る／治療できる | （肌を）健やかに保つことが期待される成分を配合 |
| シミ・シワが消える | うるおいを与える成分を配合（56効能の範囲） |
| あなたに最適な商品 | ご回答から推定される肌タイプに対応する商品 |
| 同じタイプの人によく選ばれている | 楽天市場メンズスキンケア部門 ○月度ランキング上位 |
| 安全な成分／刺激ゼロ | 「○○配合」「無香料」等の事実のみ表示 |
| 効果を保証 | （表示しない） |

> 「同じ人によく選ばれている」は**他者への推薦の暗示**にあたるため使用禁止（診断ロジック設計書 v1.1 R3）。

---

## 3. 使ってよい表現の型

- 自己申告ベース：「あなたは〇〇タイプに**該当する可能性があります**（自己申告ベース）」
- 出典付き：「楽天市場メンズスキンケア部門 ○月度ランキング上位の商品」
- 成分タグ：「肌タイプに**推奨される成分**（化粧品56効能の範囲：うるおいを与える等）を含む商品」
- 期間の目安：「一般的な目安として」と添える（断定しない）

---

## 4. 化粧品の56効能（範囲の考え方）

- 化粧品で標榜できるのは「うるおいを与える」「肌を整える」等の**56効能の範囲内**のみ。
- 医薬部外品・医薬品の効能（治療・予防の標榜）は本アプリでは扱わない。
- 成分タグの `fact_tag` は56効能の範囲内の言い回しで記述する（[DB設計書 §2.2](../design/DB設計書_v1.0.md)）。

---

## 5. ディスクレーマー（確定文言）

結果・商品系画面の**最下部に常時表示**する。文言は [診断ロジック設計書 v1.1 §8](../specs/診断ロジック設計書_v1.1.md) を正とする（抜粋）：

> 【ご注意】本診断は医学的な肌診断ではありません。…肌の状態に不安がある場合は、皮膚科医・薬剤師など専門家にご相談ください。本アプリは医療行為を行うものではなく、提案する商品の効能効果や安全性を保証するものでもありません。

- 複合タイプ表示時・初心者タイプ表示時の追記文も §8 に従う。

---

## 6. 運用フロー

1. 文言・成分タグを書いたら、本書の早見表で自己チェック。
2. たかとが一次確認（禁止表現が無いか）。
3. 迷ったら「断定をやめて事実に落とす」方向で修正。
